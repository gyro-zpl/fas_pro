### 1.2 转换为长表（核心步骤）

**转换逻辑**：
```python
宽表：1行 = 1个受访者对多个候选人的评价
      [受访者A, 对Trump的评价, 对Obama的评价, ...]

         ↓ wide_to_long()

长表：1行 = 1个受访者-候选人对
      [受访者A, Trump, 评价]
      [受访者A, Obama, 评价]
      [受访者B, Trump, 评价]
      ...
```

**转换后的数据结构**：
```
| respondent_id | resp_age | resp_race | resp_party | candidate_id | year | target |
|---------------|----------|-----------|------------|--------------|------|--------|
| 0             | 10       | white     | Republican | Trump        | 2012 | 4      |
| 0             | 10       | white     | Republican | Obama        | 2012 | 1      |
| 0             | 10       | white     | Republican | Clinton      | 2012 | 2      |
| 1             | 25       | black     | Democrat   | Trump        | 2012 | 1      |
| 1             | 25       | black     | Democrat   | Obama        | 2012 | 4      |
...

总行数：90行（每行是一个独立的训练样本）
```

**支持度映射**：
```
文本        → 数值
'unsupport'   → 1 (反对)
'neutral'     → 2 (中立偏反对)
'support'     → 4 (支持)
```

### 1.4 构造交互特征

```python
# 每个样本添加4个交互特征
1. ideology_distance = |受访者意识形态 - 候选人意识形态|
2. party_alignment = (受访者党派 == 候选人党派)
3. age_gap = |受访者年龄 - 候选人年龄|
4. race_alignment = (受访者种族 == 候选人种族)
```

**示例样本**：
```
受访者: 25岁, white, Republican, 意识形态=7
候选人: Trump, 66岁, white, Republican, 意识形态=7

交互特征:
  ideology_distance = |7 - 7| = 0        ← 意识形态完全一致
  party_alignment = (Rep == Rep) = 1     ← 同党派
  age_gap = |25 - 66| = 41               ← 年龄差大
  race_alignment = (white == white) = 1  ← 同种族

预测结果: target = 4 (支持)
```

## 2️⃣ 特征工程

### 2.1 最终特征列表（12个特征）

```python
【数值特征】(8个)
1. resp_age               # 受访者年龄
2. cand_age               # 候选人年龄  
3. cand_ideology_score    # 候选人意识形态(1-10)
4. resp_ideology          # 受访者意识形态(1-10)
5. ideology_distance      # 意识形态距离 ★重要
6. party_alignment        # 党派一致性 ★重要
7. age_gap                # 年龄差距
8. race_alignment         # 种族一致性

【类别特征】(4个)
9. resp_race              # 受访者种族
10. resp_party            # 受访者党派
11. cand_party            # 候选人党派
12. cand_race             # 候选人种族
```

### 2.2 特征处理

```python
# 数值特征：中位数填充缺失值
for col in num_cols:
    median_value = train[col].median()
    train[col].fillna(median_value)
    test[col].fillna(median_value)

# 类别特征：OrdinalEncoder编码
encoder = OrdinalEncoder(handle_unknown="use_encoded_value", unknown_value=-1)
train[cat_cols] = encoder.fit_transform(train[cat_cols])
test[cat_cols] = encoder.transform(test[cat_cols])
```

## 3️⃣ 模型训练

### 3.1 任务定义

```python
输入 X: 12个特征
输出 y: 支持度等级 [0, 1, 2, 3, 4, 5]
        0 = 强烈反对
        1 = 反对
        2 = 中立偏反对
        3 = 中立偏支持
        4 = 支持
        5 = 强烈支持

任务类型: 多分类（Multiclass Classification）
```

### 3.2 交叉验证策略

```python
策略: Leave-One-Year-Out（按年份留一交叉验证）

Fold 0:
  训练: 2014年（30个样本）
  验证: 2012年（30个样本）
  → 用2014年的数据预测2012年的支持度

Fold 1:
  训练: 2012年（30个样本）
  验证: 2014年（30个样本）
  → 用2012年的数据预测2014年的支持度
```

**为什么这样做？**
- ❌ 随机K折 → 无法验证跨年份泛化能力
- ✅ 按年份分组 → 模拟真实场景（用过去预测未来）

### 3.3 LightGBM参数

```python
params = {
    "objective": "multiclass",         # 多分类
    "num_class": 5,                    # 实际有5个类别(0,1,2,4没有3和5)
    "metric": "multi_logloss",         # 多分类对数损失
    "learning_rate": 0.05,             # 学习率
    "num_leaves": 31,                  # 每棵树的叶子数
    "feature_fraction": 0.8,           # 特征采样80%
    "bagging_fraction": 0.8,           # 样本采样80%
    "bagging_freq": 1,                 # 每轮都bagging
    "early_stopping_rounds": 50        # 50轮不提升就停止
}
```

### 3.4 训练过程

```
for each fold:
    1. 划分训练/验证集（按年份）
       ↓
    2. 构建LightGBM数据集
       - 指定类别特征
       ↓
    3. 训练GBDT模型
       - 最多500轮
       - 监控训练loss和验证loss
       - 验证loss 50轮不下降 → Early Stop
       ↓
    4. 记录最佳迭代数
       - Fold 0: 42轮
       - Fold 1: 5轮
       ↓
    5. 在验证集上评估
       - Log Loss
       - Accuracy
       - Quadratic Weighted Kappa
```

### 3.5 最终模型训练

```python
# 使用所有训练数据（60个样本）
# 迭代数 = 交叉验证最佳迭代数的中位数
final_iterations = median([42, 5]) = 23轮

最终模型: 在全部训练集上训练23轮
```

### 5.3 模型局限性

```
1. 样本量太小 (60个训练样本)
   → 交叉验证只有30%准确率
   → 部分候选人预测不准（Jason）

2. 中立态度难预测
   → 0%准确率
   → 全部被误判为反对或支持

3. 特征可能不够丰富
   → 缺少选举情境特征（初选/大选）
   → 缺少时序特征（距离选举日天数）
   → 缺少竞争环境特征（民调排名）
```

## 📊 总结

### 训练的是什么？

**学习目标**：
```
f(受访者特征, 候选人特征, 交互特征) → 支持度等级
```

**具体来说**：
- 输入：12个特征（受访者 × 候选人的匹配度）
- 输出：6个支持度等级（0-5）
- 方法：LightGBM梯度提升决策树
- 样本：60个训练样本，30个测试样本

### 数据集如何构建？

```
1. 宽表 → 长表转换
   每个受访者-候选人对 = 1个样本
   
2. 添加候选人元数据
   使模型能够泛化到新候选人
   
3. 构造交互特征
   捕捉受访者与候选人的匹配度
   
4. 按年份划分训练/测试集
   模拟真实预测场景
```

### 结果如何？

```
✅ 测试集准确率: 63.3%
✅ 新候选人Biden准确率: 80%  ← 关键成功！
✅ 已知候选人Trump准确率: 90%
⚠️ 新候选人Jason准确率: 10% ← 需要改进
```

### 最重要的发现？

```
🌟 意识形态距离是最强预测因子（73%重要性）

这意味着：
  选民倾向于支持与自己意识形态接近的候选人
  
实际例子：
  保守派选民(7分) + 保守派候选人(7分) → 高支持度
  自由派选民(3分) + 保守派候选人(7分) → 低支持度
```

---

**🎯 核心结论：宽转长建模方案在小样本测试中已经证明可行，在新候选人Biden上达到80%准确率，证明了模型的泛化能力！**
