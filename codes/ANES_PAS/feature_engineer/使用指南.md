# ANES数据宽转长工具使用指南

## 项目概述

这个工具包用于将ANES（American National Election Studies）数据从宽表格式转换为长表格式，以便进行跨年份的候选人支持度预测分析。

## 问题背景

### 挑战
- 不同年份的ANES数据包含不同的候选人
- 原始数据是宽表格式：每个受访者一行，对多个候选人的支持度分散在多列
- 难以建立统一的预测模型处理不同年份的数据

### 解决方案
将宽表转换为长表格式：
- **宽表**：1200受访者 × 11候选人 = 1200行
- **长表**：1200受访者 × 11候选人 = 13,200行（每个受访者-候选人配对一行）

## 工具文件说明

### 核心脚本

1. **`anes_wide_to_long.py`** - 核心转换脚本
   - 将单个年份的宽表数据转换为长表
   - 自动识别候选人列（ft开头）
   - 处理缺失值和特殊值（997, 998）
   
2. **`batch_process_anes.py`** - 批量处理脚本
   - 一次性处理多个年份的数据
   - 合并所有年份为一个统一文件
   - 生成数据质量报告

3. **`example_analysis.py`** - 示例分析脚本
   - 展示如何使用长表数据训练预测模型
   - 包含完整的数据处理、建模、评估流程
   - 生成可视化结果

4. **`variable_extract.py`** - 列提取工具
   - 从原始ANES数据中提取需要的列

## 数据格式说明

### 输入：宽表格式

```csv
respondent_id,birthyr,gender,race,educ,...,ftobama,fttrump,fthrc,...,pid7,ideo5,lcself
1,1960,1,1,5,...,100,1,76,...,1,6,4
2,1957,2,1,6,...,39,28,52,...,4,2,4
```

### 输出：长表格式

```csv
respondent_id,year,candidate,support_score,is_missing,birthyr,gender,...,pid7,ideo5,lcself
1,2016,obama,100.0,0,1960,1,...,1,6,4
1,2016,trump,1.0,0,1960,1,...,1,6,4
1,2016,hrc,76.0,0,1960,1,...,1,6,4
2,2016,obama,39.0,0,1957,2,...,4,2,4
2,2016,trump,28.0,0,1957,2,...,4,2,4
```

## 数据列说明

### 新增列（长表）
- `candidate`: 候选人名称（去掉ft前缀）
- `support_score`: 支持度评分（0-100）
- `is_missing`: 缺失标记（0=有效，1=缺失）

### 受访者特征列
- `birthyr`: 出生年份
- `gender`: 性别（1=男, 2=女）
- `race`: 种族
- `educ`: 教育程度
- `marstat`: 婚姻状况
- `employ`: 就业状况
- `faminc`: 家庭收入
- `votereg`: 选民登记状态

### 党派意向列
- `pid7`: 党派认同（1-7，1=强民主党，7=强共和党）
- `ideo5`: 意识形态（1-5，1=极度自由，5=极度保守）
- `lcself`: 自由-保守自评（1-7）

## 常见问题

### Q1: 如何处理不同年份的不同候选人？

A: 长表格式天然支持！每个候选人只在其出现的年份有记录。训练模型时可以：
- 使用候选人编码（LabelEncoder）
- 或者为每个候选人创建独立的虚拟变量

### Q2: 如何区分真实候选人和其他对象（如ftblack, ftwhite）？

A: 在 `example_analysis.py` 中已经处理：

```python
non_candidates = ['black', 'white']  # 这些不是候选人
df_candidates = df[~df['candidate'].isin(non_candidates)]
```

### Q3: 数据中的特殊值如何处理？

A: 脚本自动处理：
- `997` (拒绝回答) → 标记为缺失
- `998` (不知道) → 标记为缺失
- `NaN` → 保留为缺失
- 空格字符串 → 转换为NaN并填充

### Q4: 如何合并多年数据进行建模？

A: 使用 `batch_process_anes.py`，它会：
1. 处理每年数据生成长表
2. 合并所有年份
3. 创建全局受访者ID（格式：`{year}_{respondent_id}`）

### Q5: 模型性能不够好怎么办？

可以尝试：
1. **增加交互特征**：如 `pid7 × candidate`
2. **候选人特异模型**：为每个候选人训练独立模型
3. **使用深度学习**：神经网络可能捕捉更复杂的模式
4. **增加外部特征**：如候选人的政策立场、媒体曝光度等
5. **时序特征**：如果有多轮调查，可以使用之前的支持度

## 进阶使用

### 自定义候选人列表

```python
# 只保留总统候选人
presidential_candidates = ['obama', 'trump', 'hrc', 'sanders', 'biden']
df_filtered = df[df['candidate'].isin(presidential_candidates)]
```

### 创建交互特征

```python
# 党派 × 候选人交互
from sklearn.preprocessing import OneHotEncoder

# 为候选人创建独热编码
candidate_dummies = pd.get_dummies(df['candidate'], prefix='cand')

# 为党派创建独热编码
party_dummies = pd.get_dummies(df['pid7'], prefix='pid')

# 创建交互项
for cand_col in candidate_dummies.columns:
    for party_col in party_dummies.columns:
        interaction_name = f"{cand_col}_x_{party_col}"
        df[interaction_name] = candidate_dummies[cand_col] * party_dummies[party_col]
```

### 为每个候选人训练独立模型

```python
models = {}
for candidate in df['candidate'].unique():
    df_cand = df[df['candidate'] == candidate]
    X = df_cand[feature_cols]
    y = df_cand['support_score']
    
    model = RandomForestRegressor()
    model.fit(X, y)
    models[candidate] = model
```
