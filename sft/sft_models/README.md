# Trained adapters (not committed)

The LoRA adapters used by the R-protocol main table are larger than the normal
repository budget (about 87 MB each), so the weight files are excluded by
`.gitignore`. The small `adapter_config.json` files are committed so the model
configuration is auditable. The exact predictions produced by these adapters
are committed under `experiments/results/preds/`, so the main table and all
paper tables can be reproduced without loading the weights.

Reproduce the adapters:

```bash
# Qwen3-8B, 3 seeds (parallel on GPUs 0/1/3)
bash experiments/run_train_r_parallel.sh

# 2024 test_t / strict T x R retry (seed44 was interrupted and retrained)
bash experiments/run_seed44_r.sh 1

# DeepSeek-R1-Distill-Llama-8B, one seed
bash experiments/run_deepseek_r.sh 2
```

Evaluate a trained adapter:

```bash
bash experiments/run_eval_r_suite.sh 0 42:test_r:generate 42:test_t:generate
```

The adapter configs in each directory record the LoRA rank, alpha, dropout,
target modules, and base-model path. The main-table numbers are regenerated by:

```bash
python -m experiments.eval.r_protocol_tables --seeds 42,43,44
```
