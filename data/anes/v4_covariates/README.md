# v4_covariates — repaired ANES political covariates

Generated by `python -m experiments.data.repair_covariates --raw-dir ...`.
This directory does **not** modify `data/anes/v3`.

| File | Content |
|---|---|
| `anes_covariates_repaired.csv` | respondent-level `year, respondent_id, pid7, ideo5, educ, lcself` |
| `anes_candidates_base_v4cov.csv` | row-level base table (98,159 rows) with repaired covariates and recomputed `party_match` / `ideology_distance_7` |

The row-level file is **not training-ready**: the other interaction features
(`party_distance`, `demographic_similarity`, etc.) still come from v3 and must be
recomputed before any split or retrain. The next step is to run the feature
pipeline on this base table, rebuild splits, and retrain.

Mapping:

- 2018: `pid7x` instead of the placeholder `pid7`.
- 2020: `8 - pid7`; `ideo5` derived from `lcself`.
- 2024: text `pid7` / `ideo5` / `educ` mapped to numeric; `lcself` from
  `ideology_lcself`.
- 2016/2019/2022: v3 values restricted to valid ranges.

Coverage report: `experiments/results/00_covariate_repair.md`.
