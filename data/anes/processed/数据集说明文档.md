## 📝 数据格式

### JSONL格式（每行一个JSON对象）

```json
{
  "instruction": "问题描述和输入特征",
  "input": "",
  "output": "目标答案（0-100的数字）",
  "metadata": {
    "strategy": "采样策略名称",
    "year": 年份,
    "candidate": "候选人名称",
    "true_score": 真实支持度分数,
    "其他元数据": "..."
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `instruction` | String | 完整的问题描述，包含选民和候选人信息 | 见下方详细说明 |
| `input` | String | 补充输入（本任务中为空） | `""` |
| `output` | String | 预测目标（支持度分数，0-100） | `"85"` |
| `metadata.strategy` | String | 数据采样策略 | `"balanced_sampling"` |
| `metadata.year` | Integer | 调查年份 | `2020` |
| `metadata.candidate` | String | 候选人名称 | `"biden"` |
| `metadata.true_score` | Float | 真实支持度分数 | `85.0` |

## 🎯 Instruction结构详解

### Prompt级别

数据集包含三种详细程度的prompt：

#### 1. Minimal级别（简洁）
```
Predict the support score (0-100) for this voter-candidate pair.

Voter: 45yo Female White, Democrat, Liberal
Candidate: biden (Democrat President, 78yo)
Year: 2020

Score (0-100):
```

#### 2. Core级别（推荐，训练集默认）
```
Predict the support score (0-100) for this voter-candidate pair.

Voter Profile:
- Demographics: 45-year-old Female White
- Education: Bachelor's degree
- Political: Strong Democrat, Liberal

Candidate: biden
- Party: Democrat
- Position: President  
- Age: 78

Key Interactions:
- Party alignment: Same party
- Ideology distance: 0.5 (on 7-point scale)
- Age difference: 33 years
- Year: 2020

Support score (0-100):
```

#### 3. Full级别（完整，部分策略使用）
```
Predict the support score (0-100) for this voter-candidate pair in 2020.

VOTER PROFILE:
- Demographics: 45yo Female, White, Bachelor's degree
- Income level: 20/28
- Political identity: Strong Democrat (1/7)
- Ideology: Liberal (2/5)

CANDIDATE: biden
- Party: Democrat
- Position: President (Incumbent)
- Demographics: 78yo Male, White

KEY MATCHING FACTORS:
- Party alignment: ✓ Same
- Ideology distance: 0.5/7
- Age difference: 33 years (cross-gen)
- Race match: ✓
- Gender match: ✗
- Overall similarity: 0.73

Predict support score (0-100):
```

### 包含的特征信息

根据特征说明文档（`特征说明文档.md`），prompt中包含以下特征：

**受访者（选民）特征**：
- 人口统计：年龄、性别、种族、教育、收入
- 政治倾向：党派认同（7分制）、意识形态（5分制或7分制）

**候选人特征**：
- 基本信息：党派、年龄、性别、种族
- 职位信息：总统、候选人、参议员等

**交互特征**（最重要！）：
- 党派匹配度：同党派/异党派/独立选民
- 意识形态距离：7分制量表上的距离
- 年龄差异：绝对年龄差、代际分类
- 人口统计匹配：种族匹配、性别匹配
- 综合相似度：0-1之间的综合得分

**情境特征**：
- 年份：2016-2024
- 是否现任：现任总统/副总统有优势

## 🎲 训练集采样策略

训练集使用**5种核心策略**，确保数据多样性和代表性：

### 策略分布

| 策略 | 样本数 | 占比 | 说明 |
|------|--------|------|------|
| **balanced_sampling** | 999 | 40.1% | 平衡覆盖所有支持度范围 |
| **party_ideology_focused** | 594 | 23.8% | 党派×意识形态核心组合 |
| **demographic_similarity** | 400 | 16.1% | 综合相似度分层采样 |
| **cross_pressures** | 299 | 12.0% | 交叉压力（最难预测）|
| **extreme_cases** | 199 | 8.0% | 极端支持/反对 |

### 策略详解

#### 1. Balanced Sampling（平衡采样）
**目的**：确保模型能够预测全范围的支持度

**方法**：按支持度均匀采样
- `cold` [0-20)：非常不支持 → 200样本
- `somewhat_cold` [20-40)：有点不支持 → 200样本
- `neutral` [40-60)：中立 → 200样本
- `somewhat_warm` [60-80)：有点支持 → 200样本
- `warm` [80-100)：非常支持 → 200样本

**重要性**：⭐⭐⭐⭐⭐ 基础策略，防止模型偏向某个支持度范围

#### 2. Party Ideology Focused（党派×意识形态）
**目的**：重点学习最重要的两个特征组合

**方法**：采样5种关键组合
1. **完美对齐** (`perfect_align`): 同党派 + 同意识形态侧
   - 例：民主党选民 + 自由派 → 民主党自由派候选人
   - 期望：高支持度 (70-95)

2. **同党异意** (`same_party_diff_ideo`): 同党派但意识形态远
   - 例：温和派民主党选民 → 极左民主党候选人
   - 考验：党派忠诚 vs 意识形态分歧

3. **异党同意** (`diff_party_same_ideo`): 不同党派但意识形态近
   - 例：温和派选民评价对方党派的温和派候选人
   - 考验：意识形态认同 vs 党派偏见

4. **完全不匹配** (`total_mismatch`): 党派和意识形态都不同
   - 例：保守派共和党选民 → 自由派民主党候选人
   - 期望：低支持度 (5-30)

5. **独立选民** (`independent`): party_match == -1
   - 特殊群体，最难预测

**重要性**：⭐⭐⭐⭐⭐ 根据政治科学研究，党派和意识形态是最强预测因子

#### 3. Demographic Similarity（综合相似度）
**目的**：利用多维综合相似度指标

**方法**：按`demographic_similarity`特征分5档
- Very Low (0.0-0.2): 完全不相似 → 80样本
- Low (0.2-0.4): 较不相似 → 80样本
- Medium (0.4-0.6): 中等相似 → 80样本
- High (0.6-0.8): 较相似 → 80样本
- Very High (0.8-1.0): 高度相似 → 80样本

**相似度计算**：
```
demographic_similarity = 加权平均：
  - 种族匹配 (20%)
  - 性别匹配 (15%)
  - 年龄相似度 (15%)
  - 党派相似度 (25%)
  - 意识形态相似度 (25%)
```

**重要性**：⭐⭐⭐⭐ 综合性指标，捕捉多维匹配效应

#### 4. Cross Pressures（交叉压力）
**目的**：专门采样信号冲突的困难案例

**方法**：3种交叉压力情况
1. **党派忠诚 vs 意识形态分歧** (`party_vs_ideology`)
   - 同党派但意识形态距离≥3
   - 例：温和派选民评价极端派同党候选人

2. **意识形态认同 vs 党派忠诚** (`ideology_vs_party`)
   - 不同党派但意识形态距离≤1
   - 例：中间派选民评价对方党派的中间派候选人

3. **身份政治 vs 党派** (`identity_vs_party`)
   - 人口统计高度匹配但党派不同
   - 例：黑人选民评价黑人共和党候选人

**重要性**：⭐⭐⭐⭐⭐ 最难预测的情况，模型容易出错

#### 5. Extreme Cases（极端案例）
**目的**：采样极端支持和极端反对的案例

**方法**：
- 极端支持（90-100分）→ 100样本
- 极端反对（0-10分）→ 100样本

**重要性**：⭐⭐⭐ 防止模型预测过于保守，敢于给出极端预测

## 📈 预期模型学习目标

训练后的模型应该学会：

### 1. 基本规律
```
同党派 → 高支持度 (通常 60-90)
异党派 → 低支持度 (通常 10-40)
独立选民 → 中间态度 (30-60)
```

### 2. 意识形态微调
```
同党派 + 意识形态近 → 最高支持度 (80-95)
同党派 + 意识形态远 → 支持度降低 (50-70)
异党派 + 意识形态近 → 可能有一定支持 (20-50)
异党派 + 意识形态远 → 最低支持度 (0-20)
```

### 3. 人口统计效应
```
种族/性别/年龄匹配 → 轻微加分 (+5-10分)
但远不如党派和意识形态重要
```

### 4. 现任优势
```
现任总统/副总统 → 基准加分 (+5-15分)
```

### 5. 复杂权衡
当多个信号冲突时的权重：
```
党派匹配 > 意识形态距离 > 人口统计匹配 > 其他因素
```

## 🔬 评估指标

### 推荐的评估指标

#### 1. Mean Absolute Error (MAE)
```python
mae = np.mean(np.abs(predictions - true_scores))
```
- **目标**：MAE < 15 (优秀), < 20 (良好), < 25 (可接受)

#### 2. 分类准确率（5类）
将0-100分数转换为5个等级：
- 0: 强烈反对 (0-20)
- 1: 反对 (21-40)
- 2: 中立 (41-60)
- 3: 支持 (61-80)
- 4: 强烈支持 (81-100)

```python
accuracy = (predicted_bins == true_bins).mean()
```
- **目标**：准确率 > 60% (优秀), > 50% (良好)

#### 3. 按难度分层评估
```python
# 简单案例（党派完全匹配或完全不匹配）
easy_mae = calculate_mae(easy_cases)

# 困难案例（交叉压力）
hard_mae = calculate_mae(cross_pressure_cases)

# 独立选民
independent_mae = calculate_mae(independent_cases)
```

#### 4. 按候选人评估
```python
for candidate in ['trump', 'biden', 'dem', 'rep']:
    candidate_mae = calculate_mae(candidate_data)
    print(f"{candidate}: MAE = {candidate_mae:.2f}")
```

## ⚠️ 注意事项

### 1. 数据偏差
- ANES数据可能存在采样偏差
- 不同年份的样本数差异较大
- 2022和2024年数据较少

### 2. 候选人差异
- 训练集包含22个候选人，测试集只有4个
- 某些候选人（如占位符`white`、`black`）是假想候选人
- 模型对训练集中未见过的候选人可能泛化能力较弱

### 3. 时间效应
- 政治态度随时间变化
- 特定事件（如COVID-19）可能影响2020年数据
- 跨时间预测有固有的不确定性

### 4. 标签质量
- 支持度分数是受访者自我报告的
- 可能存在社会期望偏差
- 部分极端值（如999）需要清洗
