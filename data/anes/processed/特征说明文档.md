## 输出文件说明

脚本会在 `processed/` 目录下生成以下文件：

### 1. 单年份文件

- `anes_2016_with_features.csv`
- `anes_2018_with_features.csv`
- `anes_2019_with_features.csv`
- `anes_2020_with_features.csv`
- `anes_2021_with_features.csv`
- `anes_2022_with_features.csv`

**说明**: 每个文件包含该年份的原始数据和所有生成的交互特征

### 2. 合并文件

- `anes_all_years_with_features.csv`

**说明**: 合并了所有年份的数据和特征，用于跨年份分析

### 3. 训练数据文件

- **`X_features_classification.csv` - 分类任务的特征矩阵**
- **`y_target_classification.csv` - 分类任务的目标变量（5类：强烈反对=0, 反对=1, 中立=2, 支持=3, 强烈支持=4）**
- `X_features_regression.csv` - 回归任务的特征矩阵
- `y_target_regression.csv` - 回归任务的目标变量（0-100连续值）
- `feature_summary.csv` - 特征分类摘要

**说明**: 这些是预处理后可直接用于机器学习的数据

## 详细特征说明

### 3.1 受访者基础特征

这些特征描述受访者的基本人口统计信息，来自ANES原始数据。

| 特征名            | 类型  | 取值范围                           | 说明                                         |
| -------------- | --- | ------------------------------ | ------------------------------------------ |
| `age_resp`     | 数值  | 18-100                         | 受访者年龄（年）                                   |
| `gender_resp`  | 分类  | 1=男性, 2=女性                     | 受访者性别                                      |
| `race_resp`    | 分类  | 1=白人, 2=黑人, 3=西班牙裔, 4=亚裔, 5=其他 | 受访者种族                                      |
| `educ`         | 有序  | 1-6                            | 教育水平（1=小学以下, 6=研究生）                        |
| `marstat`      | 分类  | 1-6                            | 婚姻状况（1=已婚, 2=分居, 3=离异, 4=丧偶, 5=从未结婚, 6=同居） |
| `employ`       | 分类  | 1-8                            | 就业状况（1=全职, 2=兼职, 3=失业, 4=退休等）              |
| `faminc`       | 有序  | 1-28                           | 家庭收入等级（1=最低, 28=最高）                        |
| `votereg`      | 二值  | 0/1                            | 是否注册选民                                     |
| `birthyr_resp` | 数值  | 1900-2005                      | 受访者出生年份                                    |

**数据来源**: ANES原始问卷

---

### 3.2 受访者政治倾向特征

这些特征描述受访者的政治立场和党派认同。

| 特征名                   | 类型  | 取值范围  | 说明         | 计算方式                                                              |
| --------------------- | --- | ----- | ---------- | ----------------------------------------------------------------- |
| `pid7`                | 有序  | 1-7   | 7分制党派认同量表  | 原始变量<br>1=强民主党, 4=独立选民, 7=强共和党,8 not sure                         |
| `ideo5`               | 有序  | 1-6   | 5分制意识形态量表  | 原始变量<br>1=非常自由派, 3=温和, 5=非常保守派, 6=不确定                             |
| `lcself`              | 有序  | 1-7   | 7分制意识形态量表  | 原始变量<br>1=极端自由派, 4=中间, 7=极端保守派,8 not sure                         |
| `party_alignment`     | 分类  | 0/1/2 | 受访者党派倾向简化版 | 根据pid7计算：<br>0=独立选民(pid7=4)<br>1=民主党倾向(pid7≤3)<br>2=共和党倾向(pid7≥5) |
| `party_strength_resp` | 数值  | 0-3   | 受访者党派强度    | abs(pid7 - 4)<br>距离中间派的距离                                         |

**重要说明**:

- `ideo5` 和 `lcself` 都是意识形态量表，但分辨率不同
- `party_alignment` 是党派的简化版本，便于匹配计算

### 3.3 候选人基础特征

这些特征描述候选人的基本属性，来自候选人元数据文件。

| 特征名             | 类型  | 取值范围      | 说明           | 数据来源                    |
| --------------- | --- | --------- | ------------ | ----------------------- |
| `party`         | 分类  | 1/2       | 候选人党派        | 元数据<br>1=民主党, 2=共和党     |
| `ideology_cand` | 有序  | 1-7       | 候选人意识形态（7分制） | 元数据<br>1=极端自由派, 7=极端保守派 |
| `age_cand`      | 数值  | 30-90     | 候选人年龄        | 计算：year - birthyr_cand  |
| `race_cand`     | 分类  | 1-5       | 候选人种族        | 元数据<br>编码同受访者种族         |
| `gender_cand`   | 分类  | 1/2       | 候选人性别        | 元数据<br>1=男性, 2=女性       |
| `birthyr_cand`  | 数值  | 1900-1990 | 候选人出生年份      | 元数据                     |

**数据来源**: `candidate_metadata.csv` 文件

### 3.4 候选人情境特征

这些特征描述候选人的政治职位和身份地位。

| 特征名                | 类型  | 取值范围 | 说明         | 计算方式                                                                                                   |
| ------------------ | --- | ---- | ---------- | ------------------------------------------------------------------------------------------------------ |
| `position_encoded` | 有序  | 0-11 | 候选人职位编码    | 职位映射：<br>1=总统, 2=副总统, 3=候选人<br>4=前总统, 5=众议院议长<br>6=参议员, 7=州长, 8=法官<br>9=医生, 10=特别顾问, 11=众议员<br>0=其他/未知 |
| `is_incumbent`     | 二值  | 0/1  | 是否现任总统/副总统 | position in ['president', 'vice_president']                                                            |
| `is_candidate`     | 二值  | 0/1  | 是否为竞选候选人   | position == 'candidate'                                                                                |

**用途**: 捕捉候选人的政治地位对支持度的影响（现任优势效应）

### 3.5 年龄交互特征

这些特征捕捉受访者与候选人之间的年龄差异和代际关系。

| 特征名                    | 类型  | 取值范围 | 说明        | 计算方式                                                                |
| ---------------------- | --- | ---- | --------- | ------------------------------------------------------------------- |
| `age_difference`       | 数值  | 0-80 | 年龄绝对差异（年） | abs(age_resp - age_cand)                                            |
| `age_difference_ratio` | 数值  | 0-2  | 年龄差异比例    | age_difference / age_resp<br>标准化的年龄差异                               |
| `age_gap_category`     | 分类  | 3类   | 年龄代差分类    | 'same_gen': 0-15岁差<br>'adjacent_gen': 16-30岁差<br>'cross_gen': >30岁差 |
| `resp_older`           | 二值  | 0/1  | 受访者是否年长   | age_resp > age_cand                                                 |
| `age_decade_resp`      | 数值  | 1-10 | 受访者所在年龄段  | age_resp // 10<br>(如：35岁→3代表30-39岁)                                 |
| `age_decade_cand`      | 数值  | 3-9  | 候选人所在年龄段  | age_cand // 10                                                      |
| `age_decade_diff`      | 数值  | 0-7  | 年龄段差异     | abs(age_decade_resp - age_decade_cand)                              |

**研究意义**: 

- 同龄人效应：人们可能更倾向于支持与自己年龄相近的候选人
- 代际差异：不同世代可能有不同的政治偏好

---

### 3.6 党派交互特征

这些特征捕捉受访者与候选人之间的党派关系，是预测支持度的**最重要特征**。

| 特征名                         | 类型  | 取值范围   | 说明          | 计算方式                                                    |
| --------------------------- | --- | ------ | ----------- | ------------------------------------------------------- |
| `party_match`               | 分类  | -1/0/1 | 党派匹配状态      | 1: 党派匹配<br>0: 党派不匹配<br>-1: 受访者为独立选民                     |
| `same_party`                | 二值  | 0/1    | 是否同党派（简化版）  | party_alignment == party                                |
| `opposite_party`            | 二值  | 0/1    | 是否对立党派      | (受访者民主党 & 候选人共和党) \|\| (受访者共和党 & 候选人民主党)                |
| `party_distance`            | 数值  | 0-5    | 党派距离（7分制量表） | abs(pid7 - pid7_cand)<br>pid7_cand: 民主党=2, 共和党=6        |
| `pid7_cand`                 | 数值  | 2/6    | 候选人党派映射到7分制 | 民主党→2, 共和党→6                                            |
| `party_strength_x_match`    | 数值  | 0-3    | 党派强度×匹配交互   | party_strength_resp × same_party<br>强党派认同者对同党候选人的加成     |
| `party_strength_x_distance` | 数值  | 0-15   | 党派强度×距离交互   | party_strength_resp × party_distance<br>强党派认同者对异党候选人的惩罚 |

**关键洞察**:

- 党派极化：美国选民高度党派化，同党派是支持的最强预测因子
- 独立选民：party_match=-1 标识了独立选民这一特殊群体

---

### 3.7 意识形态交互特征

这些特征捕捉受访者与候选人在意识形态光谱上的距离。

| 特征名                      | 类型  | 取值范围 | 说明           | 计算方式                                         |
| ------------------------ | --- | ---- | ------------ | -------------------------------------------- |
| `ideology_cand_5scale`   | 数值  | 1-5  | 候选人意识形态（5分制） | 将7分制转换为5分制：<br>(ideology_cand - 1) × 4/6 + 1 |
| `ideology_distance_5`    | 数值  | 0-4  | 意识形态距离（5分制）  | abs(ideo5 - ideology_cand_5scale)            |
| `ideology_distance_7`    | 数值  | 0-6  | 意识形态距离（7分制）  | abs(lcself - ideology_cand)                  |
| `ideology_same_side_5`   | 二值  | 0/1  | 是否同侧（5分制）    | 都≤3 (偏自由) 或 都≥3 (偏保守)                        |
| `ideology_same_side_7`   | 二值  | 0/1  | 是否同侧（7分制）    | 都≤4 (偏自由) 或 都≥4 (偏保守)                        |
| `both_extreme_ideology`  | 二值  | 0/1  | 双方都是极端派      | (lcself≤2 或 ≥6) 且 (ideology_cand≤2 或 ≥6)     |
| `both_moderate_ideology` | 二值  | 0/1  | 双方都是温和派      | (lcself在3-5) 且 (ideology_cand在3-5)           |
| `ideology_strength_resp` | 数值  | 0-3  | 受访者意识形态强度    | abs(lcself - 4)<br>距离中间的距离                   |
| `ideology_strength_cand` | 数值  | 0-3  | 候选人意识形态强度    | abs(ideology_cand - 4)                       |

**研究意义**:

- 意识形态距离：选民倾向于支持意识形态接近的候选人
- 极端vs温和：极端派和温和派可能有不同的投票模式

---

### 3.8 人口统计交互特征

这些特征捕捉种族、性别等人口学特征的匹配效应。

#### 种族相关特征

| 特征名             | 类型  | 取值范围 | 说明       | 计算方式                            |
| --------------- | --- | ---- | -------- | ------------------------------- |
| `race_match`    | 二值  | 0/1  | 种族是否匹配   | race_resp == race_cand          |
| `both_white`    | 二值  | 0/1  | 双方都是白人   | (race_resp==1) & (race_cand==1) |
| `both_minority` | 二值  | 0/1  | 双方都是少数族裔 | (race_resp≠1) & (race_cand≠1)   |
| `cross_race`    | 二值  | 0/1  | 跨种族组合    | race_resp ≠ race_cand           |

#### 性别相关特征

| 特征名                     | 类型  | 取值范围 | 说明                   | 计算方式                                |
| ----------------------- | --- | ---- | -------------------- | ----------------------------------- |
| `gender_match`          | 二值  | 0/1  | 性别是否匹配               | gender_resp == gender_cand          |
| `female_resp_male_cand` | 二值  | 0/1  | 女性评价男性候选人            | (gender_resp==2) & (gender_cand==1) |
| `male_resp_female_cand` | 二值  | 0/1  | 男性评价女性候选人            | (gender_resp==1) & (gender_cand==2) |
| `same_gender`           | 二值  | 0/1  | 同性别（与gender_match相同） | gender_resp == gender_cand          |

**研究意义**:

- 同群体效应：选民可能对同种族/同性别候选人有更高认同
- 性别政治：不同性别组合可能影响评价（如女性对女性候选人的支持）

---

### 3.9 复合交互特征

这些是高阶交互特征，捕捉多个维度的联合效应。

#### 二阶交互

| 特征名                           | 类型  | 说明          | 计算方式                                               |
| ----------------------------- | --- | ----------- | -------------------------------------------------- |
| `party_match_x_ideology_dist` | 数值  | 党派匹配×意识形态距离 | party_match × ideology_distance_7<br>同党派但意识形态不同的情况 |
| `party_same_x_ideology_same`  | 二值  | 党派相同×意识形态同侧 | same_party × ideology_same_side_7<br>完全对齐的情况       |
| `race_match_x_party_match`    | 数值  | 种族匹配×党派匹配   | race_match × party_match                           |
| `gender_match_x_party_match`  | 数值  | 性别匹配×党派匹配   | gender_match × party_match                         |
| `age_diff_x_educ`             | 数值  | 年龄差异×教育水平   | age_difference × educ                              |
| `age_diff_x_party_dist`       | 数值  | 年龄差异×党派距离   | age_difference × party_distance                    |
| `educ_x_ideology_dist`        | 数值  | 教育×意识形态距离   | educ × ideology_distance_7<br>教育程度对意识形态分歧的调节       |
| `income_x_party_dist`         | 数值  | 收入×党派距离     | faminc × party_distance<br>收入对党派偏好的影响              |

#### 三阶交互

| 特征名                         | 类型  | 说明             | 计算方式                                                         |
| --------------------------- | --- | -------------- | ------------------------------------------------------------ |
| `party_ideology_race_align` | 数值  | 党派×意识形态×种族三重对齐 | party_match × ideology_same_side_7 × race_match<br>完全匹配的黄金组合 |

#### 综合相似度

| 特征名                      | 类型  | 取值范围 | 说明         | 计算方式                                                                                       |
| ------------------------ | --- | ---- | ---------- | ------------------------------------------------------------------------------------------ |
| `demographic_similarity` | 数值  | 0-1  | 多维度综合相似度得分 | 加权平均：<br>• 种族匹配 (20%)<br>• 性别匹配 (15%)<br>• 年龄相似度 (15%)<br>• 党派相似度 (25%)<br>• 意识形态相似度 (25%) |

**用途**: `demographic_similarity` 是一个综合指标，可单独用于快速评估整体匹配度

### 3.10 年份情境特征

这些特征捕捉时间相关的情境效应。

| 特征名                    | 类型  | 取值范围      | 说明          | 计算方式                                      |
| ---------------------- | --- | --------- | ----------- | ----------------------------------------- |
| `year`                 | 数值  | 2016-2022 | 调查年份        | 原始变量                                      |
| `is_election_year`     | 二值  | 0/1       | 是否选举年       | year % 2 == 0<br>(美国每2年选举一次)              |
| `is_presidential_year` | 二值  | 0/1       | 是否总统选举年     | year % 4 == 0                             |
| `year_normalized`      | 数值  | 0-1       | 归一化年份（时间趋势） | (year - min_year) / (max_year - min_year) |

**用途**: 

- 控制时间效应：不同年份的政治气候不同
- 选举周期：选举年和非选举年民众政治参与度不同

## 使用建议

### 1. 特征选择

根据不同的研究目的，可以选择不同的特征子集：

#### 最小特征集（基准模型）

仅使用最重要的政治特征：

```python
minimal_features = [
    'party_match',           # 党派匹配
    'ideology_distance_7',   # 意识形态距离
    'age_difference',        # 年龄差异
    'educ',                  # 教育水平
    'year'                   # 年份控制
]
```

#### 核心特征集（推荐）

包含主要的交互特征：

```python
core_features = [
    # 党派相关
    'party_match', 'party_distance', 'party_strength_resp',

    # 意识形态相关
    'ideology_distance_7', 'ideology_same_side_7',

    # 人口统计
    'age_difference', 'race_match', 'gender_match',

    # 受访者特征
    'educ', 'faminc', 'ideo5',

    # 综合指标
    'demographic_similarity',

    # 情境
    'year', 'is_incumbent'
]
```

#### 完整特征集

使用所有生成的特征（可能过拟合）

---

### 2. 缺失值处理

脚本已自动处理缺失值：

- **数值型特征**: 用中位数填充
- **分类型特征**: 用'unknown'填充
- **标记**: -1 用于标记某些无法计算的特征（如年龄段）

---

### 3. 特征重要性分析

建议的分析流程：

```python
# 1. 训练模型
from sklearn.ensemble import RandomForestClassifier
from sklearn.preprocessing import StandardScaler

# 标准化数值特征
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 训练模型
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X_scaled, y)

# 2. 查看特征重要性
```

### 5. 注意事项

#### ⚠️ 数据泄漏

- **不要使用**: 如果你的目标是预测未来支持度，不要使用那些包含未来信息的特征

#### ⚠️ 多重共线性

以下特征对高度相关，建议选择使用：

- `party_match` vs `same_party` vs `party_distance`（选1-2个）
- `ideology_distance_5` vs `ideology_distance_7`（选1个）
- `race_match` vs `cross_race`（互补，可都用）
- `gender_match` vs `same_gender`（重复，选1个）

#### ⚠️ 年份效应

- 必须包含 `year` 或 `year_normalized` 以控制时间趋势
- 如果做跨年预测，考虑时间序列交叉验证

#### ⚠️ 候选人固定效应

- 不同候选人有不同的基准支持度
- 考虑加入候选人ID的固定效应或one-hot编码
