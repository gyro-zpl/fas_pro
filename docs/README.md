## 4. 文档维护规则

- **长期追加型**文档保持固定文件名：`实验进度时间线.md`、`进度日志.md`。
- **时点快照 / 阶段报告**带日期：`运行状态_YYYY-MM-DD.md`、`D5-D7_执行记录.md`、`毕设初稿_v2_YYYY-MM-DD.pdf`。
- **计划类**只追加决策，不改写历史；范围变更必须写日期与原因。
- **实验结果不复制进 docs 正文**，只引用 `experiments/results/` 下的文件；论文里的每个数字必须可追溯到原始结果文件。
- 新增文档前先判断归属：
  - 背景、方法论、历史存档 → `01_背景与总览/`
  - 计划、清单、Gate → `02_计划与清单/`
  - 日志、执行记录、状态快照 → `03_进度与执行/`
  - 论文稿、图表、投稿材料 → `04_论文稿件/`
