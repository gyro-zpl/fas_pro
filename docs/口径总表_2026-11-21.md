- chance choice = **0.163**。
- 配对 bootstrap（LLM − HistGB，同一批 2,726 行）：ΔMAE seed42 **+0.59 [−0.17, +1.32]**、seed43 **+0.42 [−0.34, +1.19]**、seed44 **+0.89 [+0.10, +1.67]**；Δcorr **−0.040 / −0.033 / −0.039**（三者皆负）；tie-aware Δchoice **−0.057 / −0.082 / −0.083**（三者皆负）。
- 微调相对 base：ΔMAE **−2.85 / −3.01 / −2.54**；Δcorr **+0.070 / +0.077 / +0.071**。
- 权威文件：`experiments/results/paper_tables/r_protocol.md`。

### 1.3 时间边界 — T 协议（2016–2020 训练）

| 年份 | LLM corr | LLM MAE | HistGB corr | HistGB MAE |
|---|---:|---:|---:|---:|
| 2016 | 0.588 | 22.45 | 0.611 | 22.32 |
| 2018 | 0.670 | 22.25 | 0.729 | 22.02 |
| 2019 | **0.722** | 19.20 | **0.746** | 18.85 |
| 2020 | 0.478 | 25.39 | 0.560 | 23.41 |
| 2022 | 0.408 | 27.76 | 0.657 | 27.98 |
| 2024 | **−0.056** | 37.30 | **−0.008** | 35.52 |

- 2024 全量 `test_t`（3,421 行）：LLM **36.47 ± 0.75 / −0.029 ± 0.021**；HistGB **35.06 / −0.030**；常数 50 基线 **35.05**；候选人均值 **34.84**。
- recency（+2022）：**36.62 / −0.030 / choice 0.525**。
- R 模型在 2024 `test_t`：Qwen **−0.055 / −0.033 / −0.024**，DeepSeek **−0.040**，HistGB **+0.015**；strict T×R（226 行）：Qwen **−0.151 / −0.111 / −0.091**，DeepSeek **−0.121**，HistGB **+0.104**。
- **必须与协变量审计一起引用**：2024 的 pid7/ideo5/educ 全部缺失，3,421 条 prompt 只有 1 种政治档案；2020 的 pid7 刻度反向；2018 的 pid7 为哨兵 −4。因此 2024 塌缩与“没有政治协变量”混淆，2019→2020 不能读作波次效应（`00_covariate_audit.md`）。

## 2. 协议命名与禁止表述

| 场景 | 允许写 | 禁止写 |
|---|---|---|
| R 主表 | `held-out respondent numbers within a wave`；中文“同一波内留出的编号” | `unseen respondents`、`respondent-disjoint`、“没见过的受访者”、“没见过的人” |
| 面板身份 | “ANES 是面板设计，但发布文件没有跨年 person key” | “六波已确认是同一批受访者”“身份已确认”“同一编号同一个人” |
| 人物级隔离 | `person-level isolation is not verified` | “已保证”“已隔离个人” |
| T 协议 | `temporal split`、“按年份切分” | 任何“held-out person”说法 |
| test-only | 不再作为证据引用 | `test-only = 0`、`3,080/3,165 跨年` 当作面板规模 |
| 2024 | `temporal collapse` | “同一批人的长期能力下降” |

一句话：**R 协议是编号级保证，不是人物级保证。**

grep -rn "0\.518\|20\.58\|0\.714\|22\.47" thesis/ doc_latex/body_final.tex

# 3. 主表数字必须同时出现
grep -c "21\.35\|20\.73\|0\.525" thesis/chapters/03_results.tex

# 4. ACL 源与生成物一致（assemble.py 默认写 body_from_md.tex，不会覆盖 body_final.tex）
cd doc_latex && python build_md.py && python assemble.py
