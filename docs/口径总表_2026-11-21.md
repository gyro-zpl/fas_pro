### 1.1 个体级 PAS — R 协议，2016–2019，n = 2,726（**pre-repair benchmark**）

| 模型 | MAE | corr | choice（argmax 均值） | tie-aware | pred std |
|---|---:|---:|---:|---:|---:|
| **微调 Qwen3-8B（3 seeds）** | **21.35 ± 0.19** | **0.666 ± 0.003** | **0.525 ± 0.033** | **0.481 ± 0.012** | 39.6 |
| HistGB | 20.63 | 0.702 | 0.538 | 0.550 | 24.5 |
| Ridge | 22.86 | 0.639 | 0.450 | 0.474 | 23.1 |
| base Qwen3-8B | 24.15 | 0.594 | 0.478 | 0.432 | 30.5 |
| DeepSeek-R1-Distill（1 seed） | 21.37 | 0.665 | 0.572 | 0.526 | 41.0 |

- chance choice = **0.163**。
- **效果阶梯**：无信息（常数）**32.65** → 候选人均值 **32.35**（corr 0.155、choice 0.304）→ base **24.15** → Ridge **22.86** → 微调 **21.35** → HistGB **20.63**。
- **差距关闭**（分母 = base→HistGB）：MAE **79.5%**、corr **66.8%**、choice **78.0%**。换分母（无信息→HistGB）：微调 **94%**、base 自己 **71%**。两个口径都要报。
- **去掉 2018 的稳健性**（1,999 行）：base **22.23**、微调 **20.76**、HistGB **20.23**，差距关闭 **74%**，排序不变。与 79.5% 一起引用。
- **分母声明**：79.5% 与 74% 都是"同一张处理表上"两个模型之间的距离，不是到绝对上限的距离；正文已写明。
- **主检验**：论文把 **中间减两端的 MAE 对比**（+16.02，单侧 p<0.0001，受访者配对置换）定为 primary test，在 §2 的 Analysis plan 事先声明；阶梯与其它的比较只报点估计 + 区间。
- **冻结声明**：以上全部来自 v3（pre-repair）表。修复表（2024 pid7 94%、ideo5 90%、educ 100%，政治档案 1→575）只作 validity check，未用于训练；重训列为 future work（特征管线不可复现，见实施指南 §11）。
- 配对 bootstrap（LLM − HistGB，同一批 2,726 行）：ΔMAE seed42 **+0.69 [−0.09, +1.42]**、seed43 **+0.53 [−0.24, +1.29]**、seed44 **+0.99 [+0.23, +1.77]**；Δcorr **−0.039 / −0.032 / −0.038**（三者皆负）；tie-aware Δchoice **−0.052 / −0.077 / −0.078**（三者皆负）。
- 微调相对 base：ΔMAE **−2.85 / −3.01 / −2.54**；Δcorr **+0.070 / +0.077 / +0.071**。

### 1.3 时间：表观塌缩（validity，不是主结果） — T 协议（2016–2020 训练）

这一节不再作为论文主发现。逐年相关性确实下降，但其中三年不能被当作时间外推的证据；正确写法是 "apparent collapse under the processed table"。

| 年份 | LLM corr | LLM MAE | HistGB corr | HistGB MAE |
|---|---:|---:|---:|---:|
| 2016 | 0.588 | 22.45 | 0.611 | 22.32 |
| 2018 | 0.670 | 22.25 | 0.729 | 22.02 |
| 2019 | **0.722** | 19.20 | **0.746** | 18.85 |
| 2020 | 0.478 | 25.39 | 0.560 | 23.41 |
| 2022 | 0.408 | 27.76 | 0.657 | 27.98 |
| 2024 | **−0.056** | 37.30 | **−0.008** | 35.52 |

- 2024 全量 `test_t`（3,421 行）：LLM **36.47 ± 0.75 / −0.029 ± 0.021**；HistGB **35.06 / −0.030**；常数 50 基线 **35.05**；候选人均值 **34.84**。
- recency（+2022）：**36.62 / −0.030 / choice 0.525**。
- T 模型用同一 400 棵预算重训，早停选在 53 棵，逐年与 2024 全量指标不变；Appendix B.1 与 Figure 4.1 仍可直接引用。
- R 模型在 2024 `test_t`：Qwen **−0.055 / −0.033 / −0.024**，DeepSeek **−0.040**，HistGB **+0.022**；strict T×R（226 行）：Qwen **−0.151 / −0.111 / −0.091**，DeepSeek **−0.121**，HistGB **+0.109**。
- **同一份表，两种渲染**：主表 2,726 行中有 **814 行（29.9%）** 的 `pid7` 落在 1–7 之外（2018 全 727 行，2016 27 行，2019 60 行）。这些行的 prompt 显示 "Independent"，而 `party_match` 仍按 alignment 计算，出现 "Independent + Same party" 的矛盾；HistGB 侧拿到的是数值 `pid7` 与一致的 `party_match`。**两边不是同一份信息，且该差异对 LLM 不利。**
- **必须与协变量审计一起引用**：2024 的 pid7/ideo5/educ 缺失，3,421 条 prompt 只有 1 种政治档案；2020 的 pid7 刻度反向；2018 的 pid7 为哨兵 −4。因此 2024 的表观塌缩与“没有政治协变量”混淆，2019→2020 不能读作波次效应（`00_covariate_audit.md`）。
- **dropout 探针**：2019 行抹掉政治块后，LLM corr **0.714 → 0.166**、HistGB **0.734 → 0.172**；真实 2024 为 −0.055 / +0.015。输入缺失可复现大部分损失，残余不为零（`diagnostics/covariate_dropout_probe.md`）。
- **结论口径**：可以说“我们没有干净的时间泛化证据”；不可以说“LLM 四年后失效”。

### 1.6 误差剖面（第 4 章核心）

按真值四分位，每格 LLM / HistGB 的 MAE（三 seed 均值；Q1 最低真值）：

| 年份 | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| 2016 | 19.4 / 25.6 | 27.1 / 18.4 | 19.7 / 16.8 | 24.6 / 30.1 |
| 2018 | 17.1 / 21.0 | 34.4 / 19.2 | 29.8 / 19.2 | 11.2 / 27.4 |
| 2019 | 13.6 / 18.9 | 26.4 / 17.2 | 22.0 / 15.6 | 17.8 / 23.8 |

- 形态：**LLM 在 Q1/Q4 更好、Q2/Q3 更差**，三年 × 三 seed 一致；12/12 格符号符合，置换检验 p = 0.0003。
- 机制：`corr(|error|, |true − mean|)` = **−0.184**（LLM, 95% CI [−0.241, −0.127]）vs **+0.232**（HistGB, [0.184, 0.278]）；差值 **−0.416** [−0.460, −0.373]，p < 0.0001。预测标准差 LLM≈40、HistGB≈25，真值≈36。
- 检验：每个格用 respondent-cluster bootstrap（5,000 次）和配对置换检验（20,000 次，Holm 校正 12 格）；U 形对比（中间减两端）**+16.02** MAE 点 [14.33, 17.66]，单侧 p < 0.0001。11/12 格的 ΔMAE bootstrap CI 不含 0，2016 Q3 是例外（Holm p=0.0176）。
- 口径：pre-repair 表；描述性结果，但符号和 U 形在三年内稳定。
- 权威文件：`experiments/results/diagnostics/error_profile.md/.json`、`thesis/tables/table3b_profile.tex`。

## 2. 协议命名与禁止表述

| 场景 | 允许写 | 禁止写 |
|---|---|---|
| R 主表 | `held-out respondent numbers within a wave`；中文“同一波内留出的编号” | `unseen respondents`、`respondent-disjoint`、“没见过的受访者”、“没见过的人” |
| 面板身份 | “ANES 是面板设计，但发布文件没有跨年 person key” | “六波已确认是同一批受访者”“身份已确认”“同一编号同一个人” |
| 人物级隔离 | `person-level isolation is not verified` | “已保证”“已隔离个人” |
| T 协议 | `temporal split`、“按年份切分” | 任何“held-out person”说法 |
| test-only | 不再作为证据引用 | `test-only = 0`、`3,080/3,165 跨年` 当作面板规模 |
| 2024 | `apparent collapse under the processed table`；“我们没有干净的时间泛化证据” | 把 `temporal collapse` 当主发现；“同一批人的长期能力下降” |

一句话：**R 协议是编号级保证，不是人物级保证。**
