## 6. 结果回填（2026-11-25）

### A · HistGB 曲线

- `n_iter_used = 60`，`early_stopped = False`：**早停没有触发，60 棵是预算上限，不是最优点**；
- 验证 MSE 从 1,255.9（初始均值）降到 662.1，最后 10 棵仍在以 **−0.36 MSE/棵** 下降；
- 训练 MSE 485.2 vs 验证 662.1，差距 **176.9 MSE**。

结论：**基线没有收敛**，20.73 是"60 棵预算下"的误差，不是调好的误差。需要跑一个大预算确认天花板：

```bash
python -m experiments.baselines.histgb_curve --max-iter 400 --suffix _400
```

（脚本已加 `--max-iter`、`--suffix`，并会在同一份输出里报 `test_r` 主年份的 MAE / corr / choice，直接看 20.73 会变成多少。）

若 400 棵后主表 MAE 明显下降（> 0.1），要同步改 `tabular.py` 的 `max_iter` 并重跑主表；若 < 0.1，保留 60 并在方法节写明"预算绑定"。

另：旧版 `histgb_curve.md` 的表格把"初始均值"也编成了第 1 棵（共 61 行），已在新版改为 `0 = initial mean`。

### B · Q* 回测

| 目标年 | 用到的波次 | qstar（边际/两两/三路） | persistence | independence |
|---|---|---|---|---|
| 2018 | 2004–2016 | 0.0009 / 0.0037 / 0.0076 | 0.0011 / 0.0039 / 0.0078 | 0.0009 / 0.0078 / 0.0194 |
| 2022 | 2004–2021 | 0.0016 / 0.0059 / 0.0119 | 0.0034 / 0.0093 / 0.0166 | 0.0016 / 0.0092 / 0.0207 |

配对 bootstrap（2,000 次）：

- **2018**：qstar 与 persistence 打平（三路 P(qstar 更好) = 0.679，两两 0.855，边际 0.974，CI 均含 0）；
- **2022**：qstar 全面优于 persistence（三路差值 −0.0047 [−0.0058, −0.0037]，P = 1.000；两两 −0.0034，P = 1.000）；
- 两年都明显优于 independence（两两 0.0037 vs 0.0078、0.0059 vs 0.0092）。

内部一致性：A 边际与 B–C 联合的 L1 缺口 ~2e-5；B 缺口 2–3e-4；**C 缺口 9.5e-4–1.35e-3**（与"IPF 只约束 A 边际 + B–C"一致）。

论文口径建议：

> "Back-tested on 2018 and 2022, the reconstruction beats the independence reference on the pairwise joints in both years, and beats the last-wave persistence reference in 2022; on 2018 it matches persistence."

## 6. A 结果与决策（2026-11-25）

400 棵预算下早停在第 **80** 棵（最佳验证在第 75 棵），`test_r` 主年份：

| 预算 | `n_iter_used` | 早停 | 主年份 MAE | corr | choice |
|---|---:|---|---:|---:|---:|
| 60 | 60 | 否（预算绑死） | 20.731 | 0.7028 | 0.5431 |
| 400 | 80 | 是 | **20.629** | 0.7017 | 0.5383 |

ΔMAE = **−0.103**。按 `<20.6` 的硬阈值没有触发，按 `>0.1` 的差距阈值触发，正好在边界。决定采用 80 棵早停模型：`tabular.py` 的 `max_iter` 已改为 400（早停实际选 80），并重跑 R 协议主表与误差剖面。新口径：MAE gap closure **79.5%**、corr **66.8%**、choice **78.0%**；去掉 2018 为 **74%**。
