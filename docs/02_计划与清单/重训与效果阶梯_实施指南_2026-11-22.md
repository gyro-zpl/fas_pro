## 2. 阶段 A · 训练就绪表（CPU，1–2 小时）

### A1 合并修复值

`data/anes/v4_covariates/anes_covariates_repaired.csv` 是**受访者级**（year, respondent_id, pid7, ideo5, educ, lcself）。

```python
import pandas as pd
v3 = pd.read_csv("data/anes/v3/anes_candidates_clean.csv", low_memory=False)
orig = v3.copy()                      # A3 验证要用，必须在覆盖前保存
rep = pd.read_csv("data/anes/v4_covariates/anes_covariates_repaired.csv")

v3["respondent_id"] = v3["respondent_id"].astype(int)
key = ["year", "respondent_id"]
v3 = v3.merge(rep[key + ["pid7", "ideo5", "educ", "lcself"]], on=key,
              how="left", suffixes=("_old", ""))
for c in ["pid7", "ideo5", "educ", "lcself"]:
    v3[c] = v3[c].fillna(v3[c + "_old"])
    v3.drop(columns=[c + "_old"], inplace=True)
```

### A2 重算派生特征

不要手写公式。直接复用 `codes/ANES_PAS/feature_engineer/create_interaction_features.py` 里的函数（它按 `pid7` / `ideo5` / `ideology_cand` / `race_resp` / `gender_resp` 计算，列名与 v3 一致）：

```python
import importlib.util
spec = importlib.util.spec_from_file_location(
    "fe", "codes/ANES_PAS/feature_engineer/create_interaction_features.py")
fe = importlib.util.module_from_spec(spec); spec.loader.exec_module(fe)

for fn in [fe.calculate_age_features, fe.calculate_party_features,
           fe.calculate_ideology_features, fe.calculate_demographic_features,
           fe.calculate_compound_features, fe.calculate_contextual_features]:
    v3 = fn(v3)
```

**坑**：这些函数会新增/覆盖列。若某函数要求 `marstat`、`party`、`position_encoded` 等列，v3 都有；缺列会抛异常，按报错补列即可，不要静默跳过。

### A3 验证（**最关键的一步，不过就不要往下走**）

修复只应该改变“被修复的人”。所以在 2016 / 2019 / 2022 上，**修复值与原值相同的行，全部派生特征必须与 v3 完全一致**：

```python
cov = ["pid7", "ideo5", "educ", "lcself"]
changed = (orig[cov].fillna(-999) != v3[cov].fillna(-999)).any(axis=1)
out_of_range = ((orig["pid7"] < 1) | (orig["pid7"] > 7) |
                (orig["ideo5"] < 1) | (orig["ideo5"] > 5))
mask = orig.year.isin([2016, 2019, 2022]) & ~changed & ~out_of_range

skip = set(cov) | {"orig_row_id", "respondent_id", "year", "candidate", "support_score"}
derived = [c for c in v3.columns if c not in skip]
diff = (orig.loc[mask, derived].fillna(-999) != v3.loc[mask, derived].fillna(-999)).any(axis=1)
print("rows checked:", int(mask.sum()), "mismatched rows:", int(diff.sum()))   # 期望 0
```

- 期望 0：说明重算与 v3 同源，可以继续。
- 不为 0：说明公式/输入语义变了。**停**，改为从原始 long 文件端到端重建（用修复后的 pid7/ideo5/educ 覆盖 long 文件再跑整条管线），不要带着差异往下走。

同时检查修复后的缺失率，应与 `00_covariate_repair.md` 一致（2024：pid7 94%、ideo5 90%、educ 100%）。

## 3. 阶段 B · 重训（GPU，3 卡并行约 1 小时）

```bash

for s in 42 43 44; do
  CUDA_VISIBLE_DEVICES=$((s-42)) python -m experiments.train_lora \
    --train-file data/anes/v4_covariates/splits/train_r.jsonl \
    --output-dir sft/sft_models/qwen3_8b_cov_seed$s \
    --seed $s --epochs 3 --batch-size 4 --grad-accum 4 \
```

## 6. 归一化增益（论文的核心数字）

对每一项指标定义“吃掉多少差距”：

```
MAE:    (base − FT) / (base − HistGB)
corr:   (FT − base) / (HistGB − base)
choice: (FT − base) / (HistGB − base)
```

用 v3 的数字先算一遍（写进论文的表），重训后重算：

| 指标 | base | 微调 | HistGB | 吃掉差距 |
|---|---:|---:|---:|---:|
| MAE | 24.15 | 21.35 | 20.73 | **82%** |
| corr | 0.594 | 0.666 | 0.703 | **66%** |
| choice | 0.478 | 0.525 | 0.543 | **72%** |

**判定“较好”的阈值（先写死，避免事后挑）**：

- 相对 base：MAE 改善 ≥ 2.0、corr 提升 ≥ 0.05 → 微调“明显有效”；
- 相对 HistGB：MAE 差 ≤ 0.5、corr 差 ≤ 0.03 → “持平”；
- 吃掉差距 ≥ 70% → “接近上限”。

## 7. 结果判定规则（重训之后）

| 情形 | 现象 | 论文怎么写 |
|---|---|---|
| **A** | 微调仍显著优于 base，且与 HistGB 持平 | 主结论不变，数字换成修复后的；“吃掉约 X%” |
| **B** | 微调优势缩小但不消失 | 主结论弱化：“在修复后的输入上，增益为 X” |
| **C** | 微调优势消失（≈ base） | **主结论被推翻**。如实报告，并把论文重心移到“任务表征决定上限” + 数据审计 |

三种情形都要报告：修复前后两套数字、差异来源、以及“哪些结论对输入修复敏感”。

**时间章的残余**：用修复后的模型测 2024，得到 `corr_cov`。

- `corr_cov ≤ 0.2` → 残余真实存在：“修复后仍从 0.72 掉到 X”；
- `0.2 < corr_cov < 0.5` → 部分恢复：“修复解释了大部分，仍有衰减”；
- `corr_cov ≥ 0.5` → 2024 的崩主要是管道：“修复后基本恢复”。

## 8. 论文改写

### 五章结构

1. **引言**：调查很贵 → LLM 能否用 → “好用”用阶梯定义（无信息 → base → 微调 → 线性 → 提升树）。
2. **数据与基准**：清洗、两套协议、协变量审计与修复（作为基准的可信度，不当作故事中心）。
3. **个体级**：阶梯表（含三行无信息基线）+ 归一化增益 + 与 HistGB 的配对比较 + CP3 作为补充观察。
4. **群体级**：同一阶梯在 GSS 上复现（base → SFT → prior-only）。
5. **时间与方法**：探针 + 重训残余 + “模型失败 vs 输入失败”的判定规则（2 页，方法小节）。

### 新增两节的具体内容

**3.4 效果阶梯**：表 + 一句“吃掉 82%”，一句“最后 18% 是表征上限”。

**5.3 区分模型失败与输入失败**：
1. 现象：2024 corr ≈ 0；
2. 两种解释；
3. 探针：2019 抹掉政治块 → 0.714 → 0.166（已有，`00_covariate_probe`）；
4. 修复 + 重训：2024 corr 从 −0.03 → `corr_cov`；
5. 判定规则：抹掉输入能复现 → 不能归因于时间；
6. 清单：跨期评测先查党派/意识形态/教育/身份。

### 摘要与结论的三句话

1. 微调把 MAE 从 X 降到 Y，吃掉与强基线之间约 Z% 的差距；
2. 群体层面同一模式：显著靠近但不超过直接抽样；
3. 时间层面的表观塌缩大部分来自输入退化，修复后的残余为 W（或“仍待测”）。
