## 0. 一分钟版

我们让一个 8B 的开源大模型学习 ANES 调查研究数据，然后从三个层面检查它能不能当"虚拟受访者"：

1. **个体层面（PAS）**：给一个选民画像和一个候选人，预测这个选民对候选人的 0–100 评分；
2. **群体层面（FAS）**：生成一整群人的联合分布，而不只是三条边际分布；
3. **时间层面**：四年之后，这个模拟器还能不能用。

结论可以用三句话说完：

- **个体级**：在没见过的受访者上，微调后的 Qwen3-8B 与强 GBM **基本持平但略差**（MAE 21.35 vs 20.73；corr 0.666 vs 0.703）。不是"LLM 更好"。
- **群体级**：直接从重建的统计先验采样，比任何 LLM 条件都更准（EDC joint JS 0.0076 vs 最佳 LLM 0.0215）。LLM 只是"接近先验"，没有超过它。
- **时间级**：个体相关性从 2019 年的 0.72 掉到 2024 年的约 0；GBM 同样塌缩；加入 2022 年数据也不缓解。

所以这篇论文的定位不是"LLM 超过传统方法"，而是**把 structured alignment 的边界量化**：它在什么条件下有用、在什么条件下不够用。**结构化对齐是必要的，但不是充分的。**

## 1. 为什么要做这个项目

问卷调查研究是社会科学和公共政策的主要证据来源，但它很贵、很慢、很难大规模做。一个自然的想法是：**用大语言模型当虚拟受访者**——给它一个年龄、性别、教育、党派、意识形态的画像，再给它一个问题，让它直接给出回答。

这个想法已经有很多工作（Argyle et al., 2023; Dillion et al., 2023; Kim & Lee, 2023 等）。但大多数评测是 **one-shot prompting**：把画像放进上下文，问一个问题，给回答打分。它测的是"模型能不能演一个受访者"，而不是：

- 模型有没有**内化调查数据的结构**（党派、意识形态、候选人属性之间的交互）；
- 输出在**群体层面**是否连贯（不只是每条回答像，而是整个分布像）；
- 行为能不能**跨时间**保持（换一个政治环境还成不成立）。

这个项目把调查模拟拆成三个层面，分别问一个研究问题。

## 2. 三个研究问题

| 编号 | 研究问题 | 对应层面 | 一句话答案 |
|---|---|---|---|
| **RQ1** | 结构化微调能不能让一个 8B 模型成为可信的个体级受访者？它和强特征工程基线比如何？ | 个体（PAS） | 能与强 GBM 持平，但**不优于** GBM；微调显著优于 prompt-only |
| **RQ2** | 同一套 pipeline 能不能复现群体级调查分布？微调模型能不能超过重建的先验？ | 群体（FAS） | 能接近先验，但**不能超过**直接采样先验 |
| **RQ3** | 行为能不能跨调查波次迁移？ | 时间 | 四年后**个体信号塌缩**；LLM 和 GBM 都一样 |

## 3. 数据：先把数据弄干净

### 3.1 ANES（个体级）

个体级数据来自 ANES pilot waves：2016、2018、2019、2020、2022、2024。原始表有 132,948 行、3,165 名受访者、29 个候选人目标。原始表有三个问题：

1. **尾点重复名**：8,165 行的候选人名带尾点（`obama.` 和 `obama`、`hrc.` 和 `hrc`）。归一化后，其中 8,141 行是重复行，删除；剩下 24 行是唯一的，保留。
2. **群体目标混进候选人列**：`black`、`white`、`dem`、`rep` 等社会群体温度计被存进了候选人列，共 23,060 行。它们被分离到群体语料，不参与候选人 PAS。
3. **缺失/越界评分**：原始审计标记 1,550 个缺失、2,106 个越界；其中 68 行与群体目标重叠。按"先删群体目标、再删坏评分"的顺序，实际删除 3,588 行。

清洗后：**98,159 行**（132,948 − 23,060 − 3,588 − 8,141）。

### 3.2 面板结构：为什么需要两套协议

ANES 是**面板数据**：2016–2024 六个波次调查的是同一批受访者（已按原始个案编号核对），2022/2024 没有"只在测试年份出现"的受访者。所以：

- **按年份切分**（T 协议）测的是"迁移到后来的波次"，不是"泛化到新的人"；
- **按受访者切分**（R 协议）本该测"没见过的受访者"，但受下面对编号的说明限制。

两套协议回答不同问题，不能混在一起说。

### 3.3 切分

| Split | Years | Rows | 编号数 | 用途 |
|---|---|---:|---:|---|
| `train_t` | 2016–2020 | 6,516 | 2,720 | T 协议训练 |
| `val_t` | 2022 | 2,501 | 1,251 | T 协议验证 |
| `test_t` | 2024 | 3,421 | 1,712 | T 协议测试 |
| `train_r` | 2016–2020 | 5,094 | 2,131 | R 协议训练 |
| `test_r` | 2016–2022 | 6,014 | 192 | R 协议测试 |
| `test_tr` | 2024 | 226 | 113 | 严格 T×R 单元 |

注意：清洗表里的 `respondent_id` 是**每个波次内部的行号**，同一个编号在不同年份对应不同的人（例如编号 0 在 2016 与 2019 的出生年份不同）。所以上表 "Respondents" 一列是**逐年编号数**，不是面板人数；`192` 也不等于 192 个真实个体。

R 协议的做法是：按编号 hash 留出 20%；训练池是已有采样池中不在这 20% 里的部分（5,094 行、2,131 个编号）；测试集从这 20% 里按编号整组抽到 6,000 行为止（6,014 行、192 个编号）。**R 模型只在 `train_r` 上训练；`test_r` 的编号在 `train_r` 里没有出现，但因为编号逐年重排，这不等于"没见过这个人"。** 按人隔离需要从原始文件重建人物级 key。这是主结果使用的协议。

T 协议的做法是：2016–2020 训练，2022 验证，2024 测试。它用于时间分析，不用于"泛化到新的人"的主张。

### 3.4 特征

每个观察表示为一个三元组 $(v_i, c_j, y_{ij} \mid t_i)$：选民画像、候选人、0–100 温度计评分、年份。候选人身份和候选人属性解耦，候选人由元数据向量描述（党派、意识形态、年龄、职位、是否现任）。特征包括：

- **党派匹配**：+1 同党、−1 独立、0 其他；
- **七点意识形态距离**；
- **加权相似度**：党派 0.25、意识形态 0.25、种族 0.20、性别 0.15、年龄 0.15；
- **三种交叉压力**：同党但意识形态远（CP1）、异党但意识形态近（CP2）、身份相似但异党（CP3）。

这些特征同时给 GBM/Ridge 基线，保证 LLM 和表格模型看到的是同一套信号。

### 3.5 GSS（群体级）

群体级数据来自 GSS 2004–2022 的八个历史波次，目标是 2024。两个三属性配置：

- **EDC**：教育（nateduc）、毒品（natdrug）、犯罪（natcrime）；
- **EHC**：环境（natenvir）、健康（natheal）、城市（natcity）。

每个属性有三个等级（1 = too little，2 = about right，3 = too much）。真实 2024 参照样本：EDC 1,601 人、EHC 1,552 人。

## 4. 方法：两条 pipeline

### 4.1 个体级 PAS

```
选民画像 + 候选人属性 + 交互特征
        ↓  自然语言 prompt
Qwen3-8B + LoRA（r=8, α=32, dropout=0.1）
        ↓  greedy generation / anchor likelihood
0–100 评分 → 评分诱导的选择
```

- 模型：Qwen3-8B，关闭 thinking；
- LoRA 加在所有 attention/MLP 投影上；3 epochs、lr 1e-4、有效 batch 16、max length 512；只对 answer token 计 loss；21.8M 可训练参数（0.27%）；3 个 seed（42–44）。
- 读出方式：
  - **生成（generation）**：greedy 解码，解析第一个 0–100 整数；保留个体差异，是主 choice 读出；
  - **锚点似然（anchor likelihood）**：对 0,10,…,100 十一个锚点算序列对数概率，softmax 后取期望/argmax；用作校准诊断。

### 4.2 群体级 FAS

FAS 不是"让模型直接写 400 行"，而是先把历史分布重建成一个联合分布 $Q^*$，再让模型学习从 $Q^*$ 采样。三个阶段：

1. **外推**：三条边际 + 一张 B–C 两两表，用四个模型（二次回归、LOESS tri-cube、指数趋势、线性回归）加权集成，权重 1.0/1.0/0.6/0.8，归一化除以 3.4。
2. **联合重建**：用 IPF（迭代比例拟合）把边际和 B–C 表拼成一个 3×3×3 联合分布；300 次迭代，Laplace 平滑 $\alpha=10^{-6}$；另外两张两两表（A–B、A–C）从联合分布读出。Quota 条件用的是 800 次/全两两表的变体，不用于 SFT 数据。
3. **任务构造 + 微调**：从 $Q^*$ 采样的合成人口被转成五类任务——batch generation 50%、prior-constrained sampling 25%、scenario variation 15%、subgroup analysis 7%、iterative correction 3%。8B Llama-family 模型（base `llama3:8b`；GSS SFT `llama-gss-v3:8B`）在本地编排层上微调，20 行 × 20 batch，JSON 数组解析，失败 batch 跳过，最终有效 351–400 行。

### 4.3 基线

- **HistGB**：同一套特征的梯度提升树（Friedman, 2001）；
- **Ridge**：同一套特征的线性回归；
- **Base LLM**：同样的 prompt，不做微调；
- **Prior-only**：直接从 $Q^*$ 采 400 行，不用 LLM。这是 FAS 最关键的基线。

### 4.4 指标

- **MAE**：平均绝对误差，越低越好；
- **Pearson correlation**：预测和真值的线性相关；
- **rating-induced choice**：在每个 respondent–year 组里，把预测评分最高的候选人当作"选择"，和真值评分最高的候选人比；chance 是组内候选人数的倒数均值；
- **tie-aware choice**：模型输出整数，容易并列；并列时按比例给分，避免"谁在数据里排前面谁赢"；
- **JS / KL**：边际和两两联合分布的 Jensen–Shannon / 对称 KL 散度，越低越好；
- **bootstrap / paired bootstrap / cluster bootstrap**：行级、配对、按受访者聚类的置信区间。

## 5. 结果一：个体级——"competitive, not superior"

主结果使用 R 协议，2016/2018/2019 的 `test_r`，2,726 行、192 名没见过的受访者。chance choice = 0.163。

| 模型 | MAE | corr | choice（argmax） | tie-aware choice |
|---|---:|---:|---:|---:|
| **Qwen3-8B r（3 seeds）** | **21.35 ± 0.19** | **0.666 ± 0.003** | **0.525 ± 0.033** | **0.481** |
| HistGB r | **20.73** | **0.703** | **0.543** | **0.555** |
| Ridge r | 22.86 | 0.639 | 0.450 | 0.474 |
| Base Qwen | 24.15 | 0.594 | 0.478 | 0.432 |
| DeepSeek-R1-Distill r（1 seed） | 21.37 | 0.665 | 0.572 | 0.526 |

**怎么读这张表：**

- MAE 越低越好；LLM 比 GBM 高 0.62；
- corr 越高越好；GBM 高 0.037；
- choice 是"评分诱导的选择"，chance 0.163；LLM 的 0.525 与 GBM 的 0.543 很接近，但逐 seed 不稳定（0.490–0.569）；
- 模型输出整数，约 46% 的 respondent–year 组有预测 argmax 并列；tie-aware 后 LLM 0.481、GBM 0.555，**GBM 的优势更清楚**。

**配对 bootstrap（同一批 2,726 行）：**

- MAE 差：seed42 +0.59 [−0.17, +1.32]、seed43 +0.42 [−0.34, +1.19]、seed44 +0.89 [+0.10, +1.67]；差异很小，且 GBM 从不更差；
- corr 差：−0.040 / −0.033 / −0.039，三个 seed 都为负；
- argmax choice 差：+0.026 / −0.028 / −0.052，方向不稳定；tie-aware choice 差：−0.057 / −0.082 / −0.083，三个 seed 都偏向 GBM；
- 按受访者聚类的 bootstrap 把 MAE 区间从 [−0.17, +1.32] 放宽到 [−0.40, +1.61]，corr 仍为负 [−0.062, −0.019]，结论不变。

**微调有没有用？** 有。相对 base Qwen，微调把 MAE 降低 2.5–3.0，corr 提高约 0.07，choice 提高 0.01–0.09（seed-dependent）。所以"结构化对齐"至少让模型从"不可用的 prompt-only"变成"可用的同分布预测器"。

**第二个 checkpoint**：DeepSeek-R1-Distill-Llama-8B（1 seed，同一 `train_r`）达到 21.37 / 0.665 / 0.572，定性模式一致；它不是独立家族（Llama-3.1 蒸馏版），所以是"second checkpoint"，不是"second family"。

**交叉压力子群（R 模型）：**

| 子群 | LLM MAE（3 seeds） | HistGB MAE | n |
|---|---:|---:|---:|
| CP1 同党、意识形态远 | 18.94–21.73 | 21.16 | 154 |
| CP2 异党、意识形态近 | 23.59–25.80 | 23.06 | 318 |
| CP3 身份相似、异党 | **15.06–17.69** | **20.67** | 164 |
| 无冲突 | 21.15–21.48 | 20.35 | 2,090 |

LLM 在 CP3（身份 vs 党派冲突）上明显更好，在 CP1 上大致相当，在 CP2 和非冲突行上略差。样本很小，是描述性结果。

## 6. 结果二：群体级——LLM 接近先验，但没有超过先验

FAS 的关键对照不是"base LLM vs SFT LLM"，而是 **prior-only vs LLM**。直接从 $Q^*$ 采 400 行（不用 LLM）：

| 条件 | EDC marginal / joint JS | EHC marginal / joint JS |
|---|---:|---:|
| **Prior-only（无 LLM）** | **0.0004 [0.0002, 0.0023] / 0.0076 [0.0070, 0.0141]** | **0.0011 [0.0006, 0.0036] / 0.0225 [0.0192, 0.0308]** |
| LLM 最佳（v3） | 0.0040 / 0.0215 | 0.0077 / 0.0363 |
| LLM direct SFT | 0.0048 / 0.0160 | 0.0167 / 0.0470 |
| Base LLM | 0.0552 / 0.1181 | 0.0319 / 0.1001 |

**prior-only 在四个指标上都更好**；joint 的 95% CI 与 v3 不重叠（EDC 0.0141 < 0.0181；EHC 0.0308 < 0.0332）。也就是说：

- SFT 确实把 LLM 从 base 拉向 $Q^*$：EDC marginal/joint 降低 91%/86%（v3 93%/82%）；EHC 48%/53%（v3 76%/64%）；
- 但它没有超过 $Q^*$。**"fine-tuning 降低 91% JS"只是相对 base LLM 成立，不是相对经典先验成立。**

**组件分析：**

- RAG 单独接近 base（EDC 0.0473，EHC 0.0404），不是 driver；
- RAG + SFT 与 direct SFT 差不多；
- Quota annealing 不如 direct SFT，而且 15 轮内没有收敛；
- EHC 上 direct SFT 的 joint symmetric KL 反向（0.4289 → 0.5487），但 v3 两个指标都改善（0.0363 / 0.3064），所以 v3 是 EHC 的 reference run；
- coverage-adjusted：base EHC 351/400 → 0.1168/0.1850；EDC direct SFT 381/400 → 0.0377/0.0489；v3 400/400 不受影响。

**结论**：FAS 的贡献不是"LLM 能对齐群体分布"，而是"LLM 能接近一个统计先验，但经典先验本身更强；LLM 的价值需要条件生成/自然语言控制来证明"。

## 7. 结果三：时间级——四年后信号塌缩

T 协议：2016–2020 训练，2024 测试。按年看（20% held-out 行）：

| 年份 | LLM corr | LLM MAE | HistGB corr | HistGB MAE |
|---|---:|---:|---:|---:|
| 2016 | 0.588 | 22.45 | 0.611 | 22.32 |
| 2018 | 0.670 | 22.25 | 0.729 | 22.02 |
| 2019 | **0.722** | 19.20 | **0.746** | 18.85 |
| 2020 | 0.478 | 25.39 | 0.560 | 23.41 |
| 2022 | 0.408 | 27.76 | 0.657 | 27.98 |
| 2024 | **−0.056** | 37.30 | **−0.008** | 35.52 |

**关键发现：**

- 2019 → 2024，LLM corr 从 0.722 掉到 −0.056；GBM 从 0.746 掉到 −0.008。**两者都塌缩**，不是 LLM 特有。
- 2024 全量 `test_t`（3,421 行）：LLM MAE 36.47 ± 0.75、corr −0.029 ± 0.021；GBM 35.06、−0.030。
- 预测塌缩到 50：3,173/3,421 条 LLM 预测正好是 50；Biden 行全部 50（std 0），Trump 行 std 17.4、corr −0.014。
- **常数基线**：常数 50 的 MAE 是 35.05，candidate-mean 是 34.84；LLM/GBM 的 MAE 已经在 no-signal baseline 或更差。**所以 2024 的 aggregate MAE 不能当作"还有信号"的证据。**
- **recency 不缓解**：把 2022 加进训练（9,017 行），2024 仍是 MAE 36.62、corr −0.030、choice 0.525。
- **R 模型也塌缩**：2024 `test_t` 上 Qwen r corr −0.055/−0.033/−0.024，DeepSeek r −0.040；严格 226 行 T×R 单元上 Qwen r corr −0.151/−0.111/−0.091，DeepSeek −0.121，HistGB +0.104（小样本，不排序）。
- 2020 是训练年份，2019→2020 的下降是 in-domain wave difficulty，不是时间外推；真正的时间边界在 2022/2024。

**结论**：时间分布偏移应该作为 survey simulation 的一等评测轴；结构化对齐不能阻止四年后的塌缩。

## 8. 消融与其它结果

- **消融（T 协议，1 seed）**：Full 20.84 ± 0.24 / 0.679 ± 0.003 / 0.553 ± 0.011；A1 随机采样 21.27/0.658/0.543；A2 minimal prompt 21.13/0.670/0.567；A3 name-only 21.45/0.657/0.565。方向一致但效应很小，是描述性趋势，不声称每个组件必要。
- **交叉压力**：见 §5 表；CP3 是 LLM 唯一明显优于 GBM 的子群。
- **数据审计**：132,948 → 98,159；8,165 尾点命名（8,141 重复行）、23,060 群体混入、3,588 坏评分。

## 9. 这篇论文的贡献

1. **可复现的数据构造与审计**：把 ANES 的尾点重复名、群体目标混入、坏评分量化并清洗；给出 T / R 两套协议，明确面板数据的限制。
2. **个体级的诚实边界**：在真正没见过的受访者上，8B 模型与强 GBM 持平但略差；微调显著优于 prompt-only；LLM 的价值是统一接口和评分分布，不是更强的点预测。
3. **群体级的边界**：FAS 的 prior-only 基线比所有 LLM 条件都准；LLM 接近先验但不超越；群体级贡献必须从"无条件分布匹配"转向"条件生成/自然语言控制"。
4. **时间级的负面结果**：四年后 LLM 和 GBM 都失去个体信号；recency 不缓解；strict T×R 也复现。时间偏移应成为一等评测轴。

**一句话**：结构化对齐是必要的，但不是充分的；这篇论文把"必要"和"充分"之间的边界量化了。

## 10. 局限（答辩时应该主动说）

- **模型覆盖**：主 PAS 是 Qwen3-8B；第二个 checkpoint 是 DeepSeek-R1-Distill-Llama-8B（1 seed）；FAS 是 Llama-family 8B。不是多家族系统研究。
- **调查覆盖**：ANES/GSS 都是美国调查；没有跨国家、非英语、非政治领域。
- **群体态度**：九群体语料构造了但没有评测，覆盖不均。
- **面板结构**：ANES 是面板设计，但发布文件里的 `caseid`/`respondent_id` 都是波内编号（跨年 birthyr 一致率约 2%，2020 只有随机 `ResponseId`），没有可用的跨年 person ID；R 协议是 held-out respondent numbers，person-level isolation 未验证。审计见 `docs/03_进度与执行/人物级链接审计_2026-11-20.md`；T×R 只有 226 行。
- **消融**：1 seed；效应小。
- **FAS**：每个条件只生成一次；CI 只描述行抽样波动，不含 generation-to-generation 或目标样本抽样误差。
- **预训练污染**：无法排除模型在预训练中见过 ANES/GSS/选举报道；结论应读作"这些模型的行为"，不是"从零学习"。
- **choice**：rating-induced，不是实际投票；整数输出并列多，tie-aware 必须一起报。

## 12. 10 分钟汇报大纲

1. **开场（1 分钟）**：调查很贵；LLM 虚拟受访者的承诺；但 one-shot prompting 只测"演得像不像"。
2. **问题（1 分钟）**：三个层面——个体、群体、时间；三个 RQ。
3. **数据（1.5 分钟）**：ANES 审计 132,948 → 98,159；面板结构；T/R 两套协议。
4. **方法（1.5 分钟）**：PAS = prompt + LoRA + 读出；FAS = 外推 + IPF + 合成 + SFT；prior-only 基线。
5. **个体结果（1.5 分钟）**：21.35 vs 20.73；corr 0.666 vs 0.703；tie-aware choice 0.481 vs 0.555；结论"competitive, not superior"。
6. **群体结果（1.5 分钟）**：prior 0.0076 vs LLM 0.0215（EDC joint）；LLM 接近但不超越；EHC KL。
7. **时间结果（1.5 分钟）**：0.722 → −0.056；GBM 也塌；常数基线 35.05；recency 不缓解。
8. **结论/局限/下一步（0.5 分钟）**：结构化对齐必要不充分；下一步条件生成、更多模型家族、时间自适应、真实投票验证。

## 13. 术语表

| 术语 | 一句话解释 |
|---|---|
| ANES | American National Election Studies，美国选举研究调查 |
| GSS | General Social Survey，美国综合社会调查 |
| PAS | Partial Attribute Simulation，个体级"选民–候选人"评分预测 |
| FAS | Full Attribute Simulation，群体级联合分布生成 |
| T 协议 | 按年份切分：2016–2020 训练，2024 测试；测时间迁移 |
| R 协议 | 按受访者切分：`train_r` / `test_r` 的人不重叠；测没见过的受访者 |
| LoRA | Low-Rank Adaptation，一种轻量微调，只训练小的低秩适配器 |
| IPF | Iterative Proportional Fitting，迭代调整列联表使其边际/联合约束匹配 |
| $Q^*$ | 从历史 GSS 外推 + IPF 重建出的 2024 联合分布 |
| JS divergence | Jensen–Shannon 散度，两个分布的对称距离；0 = 相同 |
| KL divergence | Kullback–Leibler 散度，非对称；对近零格子敏感 |
| MAE | Mean Absolute Error，平均绝对误差 |
| Pearson corr | 预测和真值的线性相关系数 |
| Choice | 评分诱导的选择：组内预测评分最高的候选人 vs 真值最高的候选人 |
| Chance | 随机选择的准确率；组内候选人数的倒数均值 |
| Tie-aware | 预测并列时按比例给分，避免任意排序偏置 |
| Bootstrap | 有放回重采样估计置信区间 |
| Paired bootstrap | 同一批样本上比较两个模型，控制样本差异 |
| Cluster bootstrap | 按受访者（而不是行）重采样，处理面板聚类 |
| Prior-only | 直接从 $Q^*$ 采样 400 行，不用 LLM；FAS 的关键基线 |

## 14. 常见问题（第一次听汇报的人最可能问）

**Q1：为什么不用 GPT-4？**  
A：用开源 8B 模型是为了可复现、可本地训练、成本可控；GPT-4 不能本地微调，API 也会变。更大的模型/更多家族是 future work。

**Q2：为什么 GBM 这么强？**  
A：因为特征工程把党派、意识形态、候选人属性、交互都显式编码了；GBM 在小数据上非常强。LLM 的价值不是"点预测更强"，而是统一接口、评分分布、可扩展到群体生成。

**Q3：为什么 prior 比 LLM 还准？**  
A：因为 prior 就是用历史 GSS 外推 + IPF 重建出来的；LLM 是在学习这个 prior 的采样。直接采样 prior 当然更准。LLM 的潜在价值在条件生成/自然语言控制，不是无条件分布匹配。

**Q4：2024 塌缩是不是因为模型没看过 2024？**  
A：不是。加入 2022 年数据不缓解；GBM 也塌缩；R 模型也塌缩。这是分布偏移，不是"缺最近数据"。

**Q5："LLM 与 GBM 持平"是不是说明 LLM 没用？**  
A：不是。它说明在**这个任务、这个数据、这个 8B 模型**上，LLM 没有超过强特征工程；但 LLM 提供了统一接口和分布输出，且能扩展到群体生成。论文的价值是把边界说清楚，而不是夸大。

**Q6：这篇论文最大的贡献是什么？**  
A：三件事：可复现的数据审计与 T/R 协议；个体/群体/时间三个层面的边界量化；诚实的负面结果（GBM 更强、prior 更强、四年后塌缩）。

**Q7：下一步做什么？**  
A：条件生成/自然语言控制、更多模型家族、时间自适应方法、rating-induced choice 与真实投票的对照。

## 15. 一页纸总结

- **问题**：LLM 能不能当虚拟受访者？不是"演得像不像"，而是个体、群体、时间三个层面。
- **数据**：ANES 2016–2024（132,948 → 98,159 行）；GSS 2004–2022 → 2024。
- **方法**：Qwen3-8B + LoRA；R 协议（没见过的受访者）主结果；T 协议（时间）；FAS 外推 + IPF + SFT；prior-only 基线。
- **结果**：个体 21.35/0.666/0.525 vs GBM 20.73/0.703/0.543（competitive, not superior）；群体 prior 0.0076/0.0225 vs LLM 0.0215/0.0363（LLM 接近但不超越）；时间 0.722 → −0.056（两者都塌）。
- **结论**：结构化对齐必要但不充分；时间偏移是一等评测轴。
- **态度**：不夸大、不隐藏负面结果；把边界量化，让后续工作更容易校准。
