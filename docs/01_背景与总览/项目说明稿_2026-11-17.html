01

为什么要做这个项目

问卷调查研究是社会科学和公共政策的主要证据来源，但它很贵、很慢、很难大规模做。一个自然的想法是：用大语言模型当虚拟受访者。给它一个年龄、性别、教育、党派、意识形态的画像，再给它一个问题，让它直接给出回答。

这个想法已经有很多工作（Argyle et al., 2023; Dillion et al., 2023; Kim & Lee, 2023）。但大多数评测是 one-shot prompting：把画像放进上下文，问一个问题，给回答打分。它测的是“模型能不能演一个受访者”，而不是模型有没有内化调查数据的结构、输出在群体层面是否连贯、行为能不能跨时间保持。

这个项目把调查模拟拆成三个层面：个体、群体、时间。每一层问一个研究问题，也各自给出一个边界。

02

三个研究问题

RQ1 · 个体

结构化微调能不能让 8B 模型成为可信的个体级受访者？

与强特征工程基线相比如何？答案：能与 GBM 持平，但不优于 GBM；微调显著优于 prompt-only。

RQ2 · 群体

同一套 pipeline 能不能复现群体级调查分布？

微调模型能不能超过重建的统计先验？答案：能接近先验，但不能超过直接采样先验。

RQ3 · 时间

行为能不能跨调查波次迁移？

四年后还能用吗？答案：2019 到 2024 个体信号塌缩；LLM 和 GBM 都一样。

03

数据：先把数据弄干净

个体级数据来自 ANES pilot waves（2016、2018、2019、2020、2022、2024），原始表 132,948 行、3,165 名受访者、29 个候选人目标。原始表有三个问题：尾点重复名、社会群体温度计混进候选人列、缺失或越界评分。

审计的关键不是“删了多少行”，而是把每一类污染单独量化，并保留原始行索引，保证每条清洗后的记录都能追溯。

面板结构：为什么需要两套协议

ANES 是面板设计，但发布文件没有跨年 person key：原始 caseid 也是波内 1..N（跨年出生年一致率仅 1.2–2.6%），2020 只有随机 ResponseId。按年份切分（T 协议）测的是“迁移到后来的波次”，不是“泛化到新的人”；按受访者编号切分（R 协议）测的是“同一波内没见过的编号”，不是跨年没见过的同一个人；person-level isolation 未验证。

R 协议按受访者编号的 hash 留出 20% 的编号；训练池是已有采样池中不在这 20% 里的部分；测试集从这 20% 里按编号整组抽到 6,000 行为止。R 模型只在 train_r 上训练，test_r 的编号在 train_r 中没有出现；但编号逐年重排，这不等于“没见过这个人”。

特征与 GSS

每个观察是一个三元组：选民画像、候选人、0–100 温度计评分，外加年份。候选人身份与候选人属性解耦；特征包括党派匹配、七点意识形态距离、加权人口相似度，以及三种交叉压力（同党但意识形态远、异党但意识形态近、身份相似但异党）。这些特征同时给 GBM / Ridge，保证 LLM 和表格模型看到同一套信号。

群体级数据来自 GSS 2004–2022 的八个历史波次，目标是 2024。两个三属性配置：EDC（教育、毒品、犯罪）和 EHC（环境、健康、城市）；每个属性三个等级。真实 2024 参照样本：EDC 1,601 人、EHC 1,552 人。

04

方法：两条 pipeline

个体级 PAS

输入选民画像 + 候选人属性 + 交互特征
↓
Prompt自然语言任务描述，要求只输出 0–100
↓
模型Qwen3-8B + LoRA；r=8, α=32, dropout=0.1；3 seeds
↓
读出greedy generation（主 choice）；11-anchor likelihood（校准诊断）
↓
输出0–100 评分 → 评分诱导的选择

群体级 FAS

历史GSS 2004–2022 八波；3 个属性 × 3 个等级
↓
外推3 条边际 + B–C 表；二次 / LOESS / 指数 / 线性加权集成
↓
联合重建IPF：边际 + B–C；300 次；Laplace α=1e-6 → Q*
↓
合成 + 微调从 Q* 采样；五类任务；8B Llama-family SFT
↓
评测400 行 vs 2024 真实分布；prior-only 是关键基线
最关键的对照

prior-only：直接从 Q* 采 400 行，不用 LLM。FAS 的问题不是“SFT 比 base 好多少”，而是“LLM 有没有超过统计先验”。答案是：没有。

指标与统计

  • MAE ↓
  • Pearson corr ↑
  • choice（argmax）
  • tie-aware choice
  • JS / KL ↓
  • chance
  • bootstrap
  • paired bootstrap
  • cluster bootstrap

choice 是 rating-induced：在每个 respondent–year 组里，把预测评分最高的候选人当作“选择”，和真值评分最高的候选人比；chance 是组内候选人数的倒数均值。模型输出整数，约 46% 的组有预测 argmax 并列，所以主表同时报 tie-aware choice。

choice 是逐 seed 的 argmax 均值；tie-aware 在最后一列。Qwen 的 choice 区间是 0.490–0.569，逐 seed 不稳定；tie-aware 下 GBM 的优势更清楚。

怎么读

MAE 越低越好；LLM 比 GBM 高 0.62。corr 越高越好；GBM 高 0.037。choice 和 chance 0.163 比，模型确实学到了东西，但和 GBM 的 0.543 很接近。tie-aware 后 LLM 0.481、GBM 0.555。

配对 bootstrap：MAE 差 seed42 +0.59 [−0.17, +1.32]、seed43 +0.42 [−0.34, +1.19]、seed44 +0.89 [+0.10, +1.67]；差异很小，GBM 从不更差。corr 差三个 seed 都为负（−0.040 / −0.033 / −0.039）。

微调有没有用

有。相对 base Qwen，微调把 MAE 降低 2.5–3.0，corr 提高约 0.07，choice 提高 0.01–0.09（seed-dependent）。结构化对齐至少让模型从“不可用的 prompt-only”变成“可用的同分布预测器”。

第二个 checkpoint（DeepSeek-R1-Distill-Llama-8B，1 seed）达到 21.37 / 0.665 / 0.572，定性模式一致；它是 Llama-3.1 的蒸馏版，所以是 second checkpoint，不是独立家族。

SFT 有没有把 LLM 拉向先验

有。EDC marginal/joint 从 base 0.0552/0.1181 降到 direct SFT 0.0048/0.0160（91%/86%），v3 0.0040/0.0215（93%/82%）。EHC 从 0.0319/0.1001 降到 0.0167/0.0470（48%/53%），v3 0.0077/0.0363（76%/64%）。

但这些百分比是相对 base LLM，不是相对先验。先验本身仍然是更强的分布模型。

其它发现

RAG 单独接近 base（EDC 0.0473，EHC 0.0404），不是 driver；RAG + SFT 与 direct SFT 差不多；quota 不如 direct SFT，而且 15 轮内没有收敛。EHC 上 direct SFT 的 joint KL 反向（0.4289 → 0.5487），但 v3 两个指标都改善（0.0363 / 0.3064）。coverage-adjusted 后 direct SFT 的 EDC 优势明显缩小（0.0377/0.0489），v3 不受影响。

07

结果三：时间级

T 协议：2016–2020 训练，2024 测试。按年看，个体相关性从 2019 年的 0.72 掉到 2024 年的约 0。GBM 同样塌缩。

2024 全量测试

LLM MAE 36.47 ± 0.75、corr −0.029 ± 0.021；GBM 35.06、−0.030。3,173/3,421 条 LLM 预测正好是 50；Biden 行全部 50（std 0），Trump 行 std 17.4、corr −0.014。

常数 50 的 MAE 是 35.05，candidate-mean 是 34.84。LLM/GBM 的 MAE 已经在 no-signal baseline 或更差，所以 aggregate MAE 不能当作“还有信号”的证据。

这不是“缺最近数据”

把 2022 加进训练（9,017 行），2024 仍是 MAE 36.62、corr −0.030、choice 0.525。R 模型也塌缩：2024 test_t 上 Qwen r corr −0.055/−0.033/−0.024，DeepSeek r −0.040；严格 226 行 T×R 单元上 Qwen r corr −0.151/−0.111/−0.091，DeepSeek −0.121。

2020 是训练年份，2019→2020 的下降是 in-domain wave difficulty，不是时间外推；真正的时间边界在 2022/2024。

08

贡献与局限

四个贡献

  1. 可复现的数据审计。把尾点重复名、群体目标混入、坏评分量化并清洗；给出 T / R 两套协议，明确面板数据的限制。
  2. 个体级的诚实边界。在同一波内留出的编号上，8B 模型与强 GBM 持平但略差；微调显著优于 prompt-only；LLM 的价值是统一接口和评分分布。
  3. 群体级的边界。prior-only 比所有 LLM 条件都准；LLM 接近先验但不超越；群体级贡献必须从“无条件分布匹配”转向“条件生成 / 自然语言控制”。
  4. 时间级的负面结果。四年后 LLM 和 GBM 都失去个体信号；recency 不缓解；strict T×R 也复现。时间偏移应成为一等评测轴。

不声称的事

  • 不声称 LLM 在个体级优于 GBM；数据不支持。
  • 不声称 LLM 在群体级优于经典先验；prior 更准。
  • 不声称 2024 的 aggregate MAE 是“提升”；corr ≈ 0，预测塌缩。
  • 不声称跨国家、非英语、非政治领域适用；只做了 ANES + GSS。
  • 不声称多家族稳健；主 PAS 是 Qwen3-8B，第二个 checkpoint 只有 1 seed。
  • 不声称消融的每个组件必要；1 seed，效应小，是描述性趋势。
09

十分钟汇报大纲

  1. 1 min开场：调查很贵；LLM 虚拟受访者的承诺；one-shot prompting 只测“演得像不像”。
  2. 1 min问题：三个层面（个体、群体、时间），三个 RQ。
  3. 1.5 min数据：ANES 审计 132,948 → 98,159；面板结构；T/R 两套协议。
  4. 1.5 min方法：PAS = prompt + LoRA + 读出；FAS = 外推 + IPF + 合成 + SFT；prior-only 基线。
  5. 1.5 min个体结果：21.35 vs 20.73；corr 0.666 vs 0.703；tie-aware choice 0.481 vs 0.555；competitive, not superior。
  6. 1.5 min群体结果：prior 0.0076 vs LLM 0.0215（EDC joint）；LLM 接近但不超越；EHC KL。
  7. 1.5 min时间结果：0.722 → −0.056；GBM 也塌；常数基线 35.05；recency 不缓解。
  8. 0.5 min结论 / 局限 / 下一步：结构化对齐必要不充分；条件生成、更多模型家族、时间自适应、真实投票验证。

术语表与常见问题

ANES / GSS
美国选举研究调查 / 美国综合社会调查。
PAS / FAS
个体级“选民–候选人”评分预测 / 群体级联合分布生成。
T 协议 / R 协议
按年份切分 / 按编号切分；R 协议测同一波内留出的编号（人物级未验证）。
LoRA
轻量微调，只训练小的低秩适配器；不重训整个 8B 模型。
IPF
迭代比例拟合：调整列联表，使边际和联合约束匹配。
Q*
从历史 GSS 外推 + IPF 重建出的 2024 联合分布。
JS / KL
两个分布的距离；JS 对称有界，KL 非对称、对近零格子敏感。
MAE / corr
平均绝对误差 / Pearson 相关；前者越低越好，后者越高越好。
Choice / chance
评分诱导的选择准确率 / 随机选择的准确率。
Tie-aware
预测并列时按比例给分，避免任意排序偏置。
Bootstrap
有放回重采样估计置信区间；paired 比较同一批样本，cluster 按受访者重采样。
Prior-only
直接从 Q* 采样，不用 LLM；FAS 的关键基线。

第一次听汇报最可能问的

为什么不用 GPT-4？

用开源 8B 模型是为了可复现、可本地训练、成本可控；GPT-4 不能本地微调，API 也会变。更大的模型和更多家族是 future work。

为什么 GBM 这么强？

因为特征工程把党派、意识形态、候选人属性、交互都显式编码了；GBM 在小数据上非常强。LLM 的价值不是“点预测更强”，而是统一接口、评分分布、可扩展到群体生成。

为什么 prior 比 LLM 还准？

因为 prior 就是用历史 GSS 外推 + IPF 重建出来的；LLM 是在学习这个 prior 的采样。直接采样 prior 当然更准。LLM 的潜在价值在条件生成 / 自然语言控制，不是无条件分布匹配。

2024 塌缩是不是因为模型没看过 2024？

不是。加入 2022 年数据不缓解；GBM 也塌缩；R 模型也塌缩。这是分布偏移，不是“缺最近数据”。

“LLM 与 GBM 持平”是不是说明 LLM 没用？

不是。它说明在这个任务、这个数据、这个 8B 模型上，LLM 没有超过强特征工程；但 LLM 提供了统一接口和分布输出，且能扩展到群体生成。论文的价值是把边界说清楚，而不是夸大。

这篇论文最大的贡献是什么？

三件事：可复现的数据审计与 T/R 协议；个体、群体、时间三个层面的边界量化；诚实的负面结果（GBM 更强、prior 更强、四年后塌缩）。

一页纸总结

  • 问题：LLM 能不能当虚拟受访者？不是“演得像不像”，而是个体、群体、时间三个层面。
  • 数据：ANES 2016–2024（132,948 → 98,159 行）；GSS 2004–2022 → 2024。
  • 方法：Qwen3-8B + LoRA；R 协议主结果；T 协议时间；FAS 外推 + IPF + SFT；prior-only 基线。
  • 结果：个体 21.35/0.666/0.525 vs GBM 20.73/0.703/0.543；群体 prior 0.0076/0.0225 vs LLM 0.0215/0.0363；时间 0.722 → −0.056。
  • 结论：结构化对齐必要但不充分；时间偏移是一等评测轴。
  • 态度：不夸大、不隐藏负面结果；把边界量化，让后续工作更容易校准。
