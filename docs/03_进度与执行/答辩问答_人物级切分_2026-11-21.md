# 答辩问答：人物级切分与 held-out 编号（2026-11-21）

> 用途：答辩或导师汇报时，回答“test_r 是不是没见过的人”“为什么不做 person-level”“个体级结论还成立吗”。所有数字来自 `experiments/results/00_person_linkage_audit.md`，不推测、不补造。

## 一句话版本

“我们审计了发布文件：ANES 是面板设计，但 CSV 里的 `caseid` 也是波内 1..N，跨年出生年一致率只有 1.2–2.6%，2020 只有随机 `ResponseId`。所以主表只能声称 held-out respondent numbers within a wave，不能声称 unseen persons。论文的 Limitations 和 Appendix A 已写明。”

## Q1：你的 test_r 是不是没见过的人？

**答：不是。** R 切分按 `respondent_id` 哈希留出 20%，保证**同一年内编号不重叠**；但 `respondent_id` 是逐年行号，同一个人可以在另一年以另一个编号进入训练。这是编号级保证，不是人物级保证。

关键数字：

| 项目 | 数值 |
|---|---:|
| `train_r` | 5,094 行 / 2,131 个编号 |
| `test_r` | 6,014 行 / 192 个编号 |
| `test_r` 编号在 `train_r` 出现 | 0 |
| in-distribution 行（2016–2019） | 2,726 |
| 这 2,726 行来自训练侧编号 | 0 |

对照组：T 协议有 170/192 个 `test_r` 编号出现在 `train_t`，涉及 5,443/6,014 行（in-distribution 2,492/2,726 行）。这是时间协议的设计（T 在所有受访者的早期波次上训练），不是人物泄漏。

**不要说**：“unseen respondents”“respondent-disjoint”“没见过的人”。可以说：“held-out respondent numbers within a wave”。

## Q2：为什么不用原始 caseid 重建 person key？

**答：我们试过，发布文件里没有可用的跨年 key。**

六波原始 CSV 的 `caseid` 都是波内 1..N；跨年重叠 ID 的出生年一致率：

| 年份对 | ID 交集 | 出生年一致率 | 性别一致率 |
|---|---:|---:|---:|
| 2016–2018 | 1,092 | 1.7% | 49.4% |
| 2016–2019 | 1,200 | 2.6% | 51.7% |
| 2018–2019 | 2,500 | 2.0% | 51.3% |
| 2019–2022 | 1,585 | 1.8% | 48.0% |
| 2019–2024 | 1,909 | 1.2% | 0.0% |
| 2022–2024 | 1,585 | 1.6% | 0.0% |

如果同一个 ID 是同一个人，出生年应接近 100% 一致。2020 文件只有随机 `ResponseId`；processed 表的 `respondent_id` 是 0..N−1，跨年数字重叠也没有人口学一致性（出生年 0–2.6%）。结论：**不是切分代码能修的，是发布文件的可得性限制。**

需要什么：原始 ANES `.dta`/`.sav` 中的稳定个案号（如 `V160001`/`V200001`/`V240001`）或官方 panel crosswalk。拿到后按 `docs/02_计划与清单/人物级切分重跑指导_2026-11-20.md` §2–§7 跑 v4，预计 1.5–2 个工作日，GPU 半天。

## Q3：那你的个体级结论还成立吗？

**答：成立，但主张收窄。** 我们证明的是：在同一时代（2016–2019）、同一波内留出的编号上，微调模型有真实个体信号，且显著优于未微调；但与 HistGB 相比不占优。我们不主张跨年 unseen-person 泛化。

| 模型 | MAE | corr | choice | tie-aware choice |
|---|---:|---:|---:|---:|
| 微调 LLM（3 seeds） | 21.35 | 0.666 | 0.525 | 0.481 |
| HistGB | 20.73 | 0.703 | 0.543 | 0.555 |
| 未微调 LLM | 24.15 | 0.594 | 0.478 | — |
| 随机猜测 | — | — | 0.163 | — |

论文的定位是边界研究，不是“LLM 超过表格模型”。个体级结论是“structured alignment 让 8B 模型具备竞争力”；MAE 差小且依赖种子，correlation 和 tie-aware choice 都偏向 baseline，论文已如实报告。

## Q4：这算不算数据错误或论文缺陷？

**答：这是发布数据的标识限制，不是清洗错误，也不推翻结果。** 我们把它作为审计贡献：量化编号级与人物级的差别，并在 thesis Appendix A 给出六波 ID 范围、跨年一致率和 R/T 重叠表。它限制的是主张边界；时间崩溃（2024 corr ≈ 0）和 FAS prior 更强的负结果不依赖 person-level。

## Q5：如果委员会坚持要 person-level 怎么办？

**两条路：**

1. **拿到原始 `.dta`/`.sav` 或官方 panel ID crosswalk** → 按 v4 指南重跑切分、训练、评测；预计 1.5–2 个工作日。
2. **拿不到** → 保持 held-out-number 口径，在 Limitations 明确 “person-level isolation unverified”；不把编号切分包装成人物切分。

**不要用 demographic matching（birthyr + gender + race）硬造 key**：碰撞率高，会把同画像的人当成同一人，审稿人一眼能看穿。

## 口径对照表

| 场景 | 可以写/可以说 | 不要写/不要说 |
|---|---|---|
| R 主表 | held-out respondent numbers within a wave | unseen respondents; respondent-disjoint |
| T 协议 | temporal split; reuses respondents across waves | held-out persons |
| 2024 对比 | temporal collapse | 同一批人的长期追踪 |
| 身份 | released files lack a cross-wave person key | 身份已确认；六波同一批人已核对 |
| 人物级隔离 | unverified | 已完成；已保证 |
