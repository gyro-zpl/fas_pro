# 第一轮论文评审（2026-11-10）

> 对象：`thesis/main.pdf`（UMAC FST 英文硕士论文，正文 10 页，总 25 页）
> 评审方式：按方法论、结果/统计、写作/结构、伦理/局限四个维度做结构化评审
> 结论：**Major Revision**（核心实验与结论可辩护，但有若干必须补强的点）

---

## 1. 总体评价

这是一篇**诚实、控制得比较好**的硕士论文。它没有把"LLM 与 GBM 持平"包装成"LLM 更好"，而是把负面结果（2024 塌缩）写成时间边界分析，这是全文最有价值的部分。数据审计（132,948 → 98,159；尾点重复名、群体混入、面板结构）是实打实的方法贡献；FAS 在 EDC 上的 −91%/−86% 也足够强。

但论文目前更像一篇"加长版会议论文"，而不是一篇完整的硕士论文：FAS 的生成方法没有交代清楚，只有一个模型家族，预训练污染没有讨论，消融只有 1 seed。这些问题不致命，但答辩前必须处理。

**建议：Major Revision。**

---

## 2. 优点

1. **诚实的结果报告**：主结果明确写"competitive, not superior"，并用 paired bootstrap 给出 ΔMAE +0.60 [−0.19, +1.42]、Δcorr −0.039 [−0.056, −0.021]、Δchoice +0.026 [−0.007, +0.062]。这比很多同类工作可信。
2. **面板数据的处理**：明确指出 3,080/3,165 跨年、2022/2024 无 test-only 受访者，并设计 T / R / T×R 三套协议。这是方法上的亮点。
3. **数据审计**：把尾点重复名（8,165）、群体混入（23,060）、异常评分（3,588）量化并清洗，可复现。
4. **FAS 的 coverage-adjusted 分析**：把缺失行按最大 JS=ln2 计惩罚，base EHC 从 0.0319/0.1001 调整为 0.1168/0.1850，v3 保持 0.0077/0.0363。这个细节很专业。
5. **时间边界分析**：2019→2024 的 corr 0.722 → −0.056，且 GBM 同样塌缩；recency + 2022 不缓解。这个负面结果比"2024 变好"更有论文价值。

## 3. 主要问题（必须处理）

### C1. FAS 的生成方法没有交代清楚（Critical）

**位置**：Chapter 2.4（Population-Level Pipeline）、Chapter 3.2（Population-Level Results）。

论文描述了"五类任务"和"base / SFT / RAG / quota"四种条件，但没有说明：

- 400 条样本是用哪个模型生成的？Qwen3-8B？Llama？Dify 背后是什么模型？
- 生成时的 prompt、temperature、batch size、解析/重试策略是什么？
- "base"、"SFT"、"RAG"、"RAG+SFT" 分别对应什么训练/检索配置？
- 每个条件生成一次还是多次？400 条是否来自多个 batch 的拼接？

**为什么严重**：FAS 是论文两大贡献之一；没有这些信息，读者无法判断 EDC 的 −91% 是方法效果还是生成配置差异。这是可复现性的硬伤。

**建议**：在 Chapter 2.4 加一段 "Generation setup"，并在 Appendix C 给出完整 prompt 和生成参数（模型、temperature、batch、解析、样本数、失败率）。代码里已有 `codes/GSS/DIFY_*` 和 `FAS_GSS.py`，把实际配置写清楚即可。

### C2. 只有一个模型家族（Critical / Important）

**位置**：Chapter 5.1（Limitations）。

所有微调实验只用 Qwen3-8B；Llama-3.1-8B 因 gated 未评测。论文承认了这一点，但标题和摘要的表述仍像是一般性结论。

**建议**（二选一）：

- 补一个**单 seed 的第二模型家族**（Llama-3.1-8B 或 Qwen3-4B），只跑 `train_t` + `test_r 2016–2019`，放进 Appendix；或
- 在标题/摘要/结论中明确限定 "a Qwen3-8B case study"，不要写成对 LLM 的一般性结论。

对于硕士论文，前者更稳；如果拿不到 Llama，至少加一个同家族不同规模（Qwen3-4B）的 pilot。

### C3. 预训练污染没有讨论（Critical）

**位置**：Chapter 5.1 缺失。

Qwen3-8B 的预训练语料可能包含 ANES/GSS 数据、2020/2024 选举报道、民调结果。模型在 2016–2019 上的"信号"可能部分来自记忆，而不是学习。2024 的塌缩也可能与知识截止/污染有关。

**建议**：

- 在 Limitations 增加一段 "Pretraining contamination"；
- 如果时间允许，做一个简单检查：让 base 模型直接回忆 2024 的选举结果/民调，或比较模型对训练年份与未来年份的"熟悉度"；
- 至少明确：本文不能排除预训练污染，结论应理解为"在该模型上的行为"，而非"从零学习"。

### C4. 个体级主张是"持平"，需要更清楚地回答"为什么还要用 LLM"（Critical / Important）

**位置**：Chapter 1（贡献 2）、Chapter 3.1、Chapter 5（结论）。

论文很诚实地写了 LLM 与 GBM 持平，但"LLM 的价值是统一接口 + 分布输出"目前只是断言，没有实验证明。审稿人/答辩老师会问：既然 GBM 一样好，为什么不用 GBM？

**建议**（至少做一个）：

- 展示一个 GBM 做不到的能力：例如用 candidate metadata 零样本预测**新候选人**（2024 的 Biden/Trump 之外），或自然语言条件（"如果候选人支持环保政策"）下的预测；
- 或者把论文明确框定为"**边界研究**"：不是证明 LLM 更好，而是量化 structured alignment 在什么条件下有效、什么时候失效。这样"持平"本身就是结果，而不是缺陷。

当前 Introduction 已有这个倾向，但需要更明确地写成 research questions（RQ1/RQ2/RQ3），而不是"四条贡献"的列表。

### C5. 消融证据偏弱（Important）

**位置**：Chapter 4.3、Appendix B.2。

A1/A2/A3 各 1 seed，效应只有 0.4–0.6 MAE、0.02 corr，choice 在噪声范围内。论文写"data-design story is real but small"，这是诚实的，但"real"需要更多 seed 支撑。

**建议**：

- 补 A1 和 A3 各 2 个 seed（共 4 次训练，约 3–4 小时），报告 mean±std；或
- 把措辞改成 "a small, consistent trend"（而不是 "real"），并在 Limitations 明确 1 seed 的限制。

### C6. FAS 没有不确定性（Important）

**位置**：Chapter 3.2、Table 3.2。

JS 是在 400 条生成样本上算的，没有置信区间；91% vs 93%、76% vs 64% 的差异可能落在采样噪声里。真实样本 1,552/1,601，生成样本 400，比例不对等。

**建议**：对生成样本做 bootstrap（按行重采样 1000 次），给 marginal/joint JS 的 95% CI；或重复生成 3 次，报告 mean±std。至少要在表中加一列 CI。

## 4. 次要问题（建议处理）

1. **Related Work 偏薄**（Chapter 1.1）：18 条参考文献，主要是 2022–2025 的 LLM 工作。建议补 5–10 条：
   - Argyle et al. 的正式发表版（Political Analysis, 2023）；
   - Brand et al. (2023) 关于 LLM 作为社会科学家助手；
   - Tjuatja et al. (2023) 关于 LLM 的人类相似响应偏差；
   - Bisbee et al. (2024) 关于合成调查数据；
   - 以及 ANES/GSS 的方法论文献。
2. **参考文献不完整**：arXiv 条目只有标题，没有 arXiv ID/URL；Argyle 2022 缺 venue。`apalike` 不会显示 `eprint` 字段，需要在 `@misc` 里加 `howpublished={arXiv:...}` 或 `url`。
3. **缺少 pipeline 图**：全文只有 Figure 4.1（时间衰减）。建议加一张紧凑的 pipeline 图（数据 → 特征 → LoRA → 读出 → PAS/FAS），放 Chapter 2 或 Appendix；正文 10 页很紧，可放 Appendix。
4. **"first such comparison" 表述过强**：Chapter 1.1 结尾说 "to our knowledge, the first such comparison on a common panel"——建议保留 "to our knowledge"，但加一句 "on this benchmark" 限定。
5. **标题页格式**：`thesiscover.doc` 是学校封面模板，当前标题页是仿写的；建议逐字核对 "Master of Computer Science"、学院/系名称、日期格式，以及是否需要 Declaration/Acknowledgments/Preface。
6. **Choice 指标**：rating-induced choice 已说明，但可以补一句"在有个体投票变量的年份，rating-induced 与真实投票的一致率"，增强效度。
7. **Figure 4.1 caption 有 7.8pt overfull**：缩短 caption 或调整图宽。
8. **Appendix C 的 prompt 示例太短**：建议给出完整的 system + user prompt（PAS 与 FAS 各一），以及输出格式约束。

## 6. 最终判断

**Major Revision**。

核心实验、数据清洗、FAS 主结果、时间边界分析都足以支撑一篇硕士论文；但 FAS 生成细节、单模型限制、预训练污染、消融稳健性是答辩前必须补的。修改后可以达到"pass with minor revisions"的水平。

最需要避免的写法是把"LLM 与 GBM 持平"藏起来，或者把 2024 的塌缩说成"方法有效"。当前论文没有这样做，这是它最大的优点，修改时应保持这一点。
