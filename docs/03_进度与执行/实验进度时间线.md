## 2026-11-12 — 第二轮论文评审

- 完成第二轮 review：`docs/03_进度与执行/论文评审_第二轮_2026-11-12.md`
- 结论：Major Revision（定向）。核心 boundary study / 2024 塌缩仍成立，但发现三处 P0：
  - **R 协议并非 respondent-disjoint**：主模型用 `train_t` 训练；`test_r` 192 个编号中 170 个（88.5%）在 `train_t` 出现，2016–2019 的 2,726 行中 2,492 行（91.4%）来自见过的编号。`run_train_r_seeds.sh` 存在但未运行。
  - **choice 0.518 是池化伪影**：per-seed choice 为 0.560/0.538/0.562（均值 0.553 ± 0.011）；3 seed 拼接后按组 argmax 得到 0.519，且随行顺序在 0.40–0.45 波动。tie-aware choice 约 0.510 vs HistGB 0.546。
  - **FAS 缺少 prior-only 基线**：直接从重建的 $Q^*$ 采样 400 行，EDC marginal/joint JS = 0.0004/0.0076，EHC = 0.0011/0.0225，优于最好 LLM 条件（EDC v3 0.0040/0.0215；EHC v3 0.0077/0.0363）。
- 另发现：FAS 方法描述与代码不一致（论文写 800 iters/all pairs；实际 SFT 数据路径为 300 iters/Pbc+Pa）、数据审计表重复计数 8,141 行、FAS uncertainty Limitations 与新增 CI 自相矛盾。
