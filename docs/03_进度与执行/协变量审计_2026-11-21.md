## 3. 两处编码缺陷

**2020 的 pid7 反向**：

| 波次 | corr(pid7, lcself) | corr(party_match, score) |
|---|---:|---:|
| 2016 | **+0.658** | +0.367 |
| 2019 | **+0.708** | +0.466 |
| 2020 | **−0.546** | **−0.223** |

2020 的 “Strong Democrat” 实际是强烈共和党人。`train_r` 里 2,545 / 5,094 = **50%** 来自 2020。

**2018 的 pid7 全为 −4**：但原始 `pid7x` 有效 96.1%，当前表取错了列。`party_alignment` 因此恒为民主党，而 prompt 渲染成 “Independent”，同一句里出现 “Independent … Same party”。主表 2,726 行里有 **727 行（27%）** 受此影响。

## 4. 影响范围

| 结论 | 影响 |
|---|---|
| LLM vs HistGB 的相对比较 | **不受影响**（两边吃同一份特征） |
| 个体级绝对数字 | 偏悲观，且 LLM 额外被文本矛盾拖累 |
| 2019→2020 下降的解释 | **不成立**：不是波次难度，是缺失 + 反向编码 |
| 2024 塌缩的解释 | **大部分由输入缺失解释**；但输入缺失本身是 pipeline artifact；仍有一个较小的年份/候选人集残余偏移 |
| FAS（群体级） | 不受影响（不用 ANES 协变量） |

## 6. 协变量 dropout 探针（已完成）

脚本：`experiments/diagnostics/covariate_dropout_probe.py`；结果：
`experiments/results/diagnostics/covariate_dropout_probe.md/.json`。

做法：复用 seed42 的 2019 已落盘预测，只对“抹掉政治块”的版本重新推理；HistGB 用同一 `train_r` 配方拟合并分别预测原始/抹除特征。抹除后的 prompt 只有 1 种政治档案，与 2024 相同。

| 条件 | 模型 | MAE | corr | choice | pred SD |
|---|---|---:|---:|---:|---:|
| 原始 | LLM | 19.34 | 0.714 | 0.665 | 38.9 |
| 抹除政治块 | LLM | 31.67 | 0.166 | 0.356 | 12.2 |
| 原始 | HistGB | 19.04 | 0.734 | 0.649 | 25.0 |
| 抹除政治块 | HistGB | 31.46 | 0.172 | 0.356 | 7.0 |

1,302 行 / 191 个 respondent 组；chance 0.150。抹除后 LLM 只输出 50/99/0 三个值（1,219 行为 50）。

实际 2024（同 seed42 R 模型 / HistGB）：corr −0.055 / +0.015，MAE 37.78 / 35.11。结论：**大部分塌缩可由输入缺失解释，但残余不为零**（2019 抹除 corr 0.166，2024 实际 −0.055）；2024 不能读作“纯政治环境变化”。
