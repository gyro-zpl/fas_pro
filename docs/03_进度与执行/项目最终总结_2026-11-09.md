# 项目最终总结（2026-11-09）

> 本文档总结从 2026-11-04 到 2026-11-09 的重构、实验、分析与初稿工作。
> 详细时序见 `03_进度与执行/实验进度时间线.md`，结果登记见 `论文可用结果_2026-11-07.md`。

---

## 1. 一句话总结

我们把原来的"prompting-only 评测"重构为**数据驱动的对齐 pipeline**，在 ANES 个体级、GSS 群体级、以及 2019→2024 时间边界三个层面做了系统实验。结论是：**structured alignment 是必要的，但不是充分的**——它能让 8B 模型在同分布陌生人上达到与强 GBM 持平的水平，并在 EDC 上把分布差异降低约 90%，但无法阻止四年后的时间塌缩。

---

## 2. 核心发现

### C1 个体级：competitive, not superior

| 模型 | MAE | corr | choice | chance |
|---|---|---|---|---|
| Fine-tuned Qwen3-8B（3 seeds） | 20.84 [20.38, 21.30] | 0.679 [0.666, 0.692] | 0.518 [0.481, 0.552] | 0.163 |
| HistGB | 20.58 [20.01, 21.12] | **0.714 [0.696, 0.733]** | 0.534 [0.498, 0.569] | 0.163 |
| Base Qwen3-8B | 24.16 [23.44, 24.88] | 0.593 | 0.479 | 0.163 |

- Paired bootstrap：LLM−GBM 的 ΔMAE +0.60 [−0.19, +1.42]、Δchoice +0.026 [−0.007, +0.062]，均不显著；Δcorr −0.039 [−0.056, −0.021]，GBM 显著更高。
- 微调 vs base：ΔMAE −2.98 [−3.82, −2.10]，Δcorr +0.082，Δchoice +0.081，显著改善。

### C2 群体级：EDC 强，EHC 中等

| config | 条件 | marginal JS | joint JS |
|---|---|---|---|
| EDC | base | 0.0552 | 0.1181 |
| EDC | SFT (381/400) | 0.0048（−91%） | 0.0160（−86%） |
| EDC | SFT-v3 (400/400) | **0.0040（−93%）** | **0.0215（−82%）** |
| EHC | base (351/400) | 0.0319 | 0.1001 |
| EHC | SFT-v3 (400/400) | **0.0077（−76%）** | **0.0363（−64%）** |

- RAG 单独使用无效；RAG+SFT ≈ SFT；quota 不如 SFT。
- EHC 的 joint symmetric KL 反而上升（0.43→0.55），以 JS 为主指标。

### C3 时间边界：两者都失效

| 年份 | LLM corr | GBM corr |
|---|---|---|
| 2019 | 0.722 | 0.746 |
| 2020 | 0.478 | 0.560 |
| 2022 | 0.408 | 0.657 |
| 2024 | **−0.056** | **−0.008** |

- 2024 上 LLM 的 3,421 条预测中 3,173 条为 50；Biden 行全部 50（std=0）。
- recency + 2022（9,017 条）后 2024 corr 仍为 −0.030，没有缓解。
- 这不是 LLM 特有：GBM 同样失效。

### 数据与消融

- 132,948 → 98,159 行；删除尾点重复名 8,165、群体混入 23,060、异常评分 3,588。
- 面板：3,080/3,165 跨年；2022/2024 的 1,909 名受访者全部在训练年份出现过；test-only = 0。
- 消融（1 seed）：Full 20.84/0.679/0.553；A1 21.27/0.658/0.543；A2 21.13/0.670/0.567；A3 21.45/0.657/0.565。数据设计有 2–3% 小幅贡献。
- 交叉压力：LLM 在 CP3（身份匹配/异党）MAE 15.5–17.8，GBM 20.31；CP1 持平；CP2/非冲突 GBM 略好。

## 5. 论文可用主张（写/不写）

**可以写：**

- 结构化微调让 8B 模型在同分布陌生人上与强 GBM 持平，并显著优于 prompt-only。
- FAS 在 EDC 上把边际/联合 JS 降低 91–93% / 82–86%。
- 时间偏移下 LLM 与 GBM 都失去个体信号；LLM 衰减更早；recency 不缓解。
- 数据清洗与 T/R 协议是必要的方法贡献。

**不要写：**

- "LLM 优于 GBM"（统计不支持）。
- "2024 上 MAE 下降 = 提升"（corr≈0，塌缩）。
- "EHC 也降低 80%"（只有 −76%/−64%）。
- "跨领域适用"（只做了 ANES + GSS）。

## 7. 最终判断

这是一项**证据自洽、结论诚实**的工作：

- 数据贡献扎实（清洗、面板协议、可复现切分）。
- FAS 的 EDC 结果强，足以支撑 C2。
- 时间边界是全文最有价值的结果，且是负面结果——它比"2024 变好"更可信。
- 个体级与 GBM 持平不是失败，而是把主张校准到数据能支持的范围。

如果目标是"讲一个不夸大的故事"，当前材料已经足够写出一版可投稿的初稿；如果目标是"LLM 显著超过 GBM"，需要换模型/换数据/换任务，当前证据不支持。
