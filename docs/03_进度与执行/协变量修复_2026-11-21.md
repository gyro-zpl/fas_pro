## 1. 原始文件里有什么

| 波次 | 原始列 | 当前 v3 表 | 原因 |
|---|---|---|---|
| 2024 | `pid_pid1d` / `pid_pid1r` / `pid_dstr` / `pid_rstr` / `pid_partylean`、`ideology_lcself`、`educ` | `pid7`/`ideo5`/`educ` 全缺 | 2024 是文本标签（`Strong Democrat`、`Liberal`、`High school graduate`），特征工程按数值读取，整列变 NaN |

| 2016/2019/2022 | 有 `pid7`/`ideo5`/`educ`，但含 8/9/-7 等非实质码 | 被当成有效值 | 限制到 1–7 / 1–5 / 1–6 |

## 3. 对论文的含义

- **不能写“2024 file carries no party/ideology/education item”**；原始 CSV 有，只是当前 processed table 没映射。
- 正确写法：`the processed analysis table loses the 2024 covariates during extraction; the raw file stores them as text labels`。
- 2018 的 727/2,726 行（27%）和 2020 的 2,545/5,094 行（50% 训练数据）受编码问题影响；修复后主表数字可能变化。
- 2024 恢复协变量后，时间塌缩可能明显变小；**当前的时间结论必须等重跑后才能定稿**。
